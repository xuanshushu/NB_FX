T08 · 真正 VFX Mesh 单粒子溶解最终颜色数值检查点

限定结论：在隔离 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal Player 中，真正 Output Particle Shader Graph Mesh 的 Off / Single / ProcessMask 受控一粒子测试通过：各组 alive=1、非剔除、可见像素 676；安全 ROI 576，重复截图 RGB 最大差 0；生成 Shader 与运行时保留精确 NBCameraOpaqueDistortPass、NBDeferredDistortPass（运行时索引 1/2）。Single 最终颜色比值中位数 0.918756（预测 0.919166）；ProcessMask 1.0，Off 与 ProcessMask 整张线性读回一致。构建 0 error/31 warning，Player 退出 0。这是最终颜色限定数值测试，不是 GPU alpha 直接读回、NBPostprocess Mask/RT/Uber 验证或原 ShaderLab B/C 严格等价，也不放行 G5/G6。

输入为显式线性 1×1 灰度 133/255 DissolveMap、白色 DissolveMaskMap 与白色 BaseMap；三份 VFX 只切换 Output 的 Single/ProcessMask 两开关，宿主仅允许一个存活粒子。共享 V3 公式给出的单片覆盖为 saturate(10×133/255−4.5)=0.715686，ProcessMask 覆盖 1。产品样例 Mesh 是闭合 Cube，隐藏 Graph Material _Cull=0；前后两面均以 SrcAlpha/OneMinusSrcAlpha 混合，故最终画面比值预测为 1−(1−0.715686)²=0.919166。两面解释是由 Mesh/Cull 状态及数值吻合所支持的推断，尚非逐片 GPU 抓取证明；不能拿 0.918756 与单片 0.715686 直接判产品失败。
