Noise 共享抽取：原 NBShader 没有变化

人话结论：为了让 Graph 重用原噪声计算，先把“读 RG、按需转成正负值、读取 Alpha 权重”这三步移成共享函数。原 NBShader 与冻结版本的 92 项 Mesh 对照全部完全一致，开关也确实有效。这只证明抽取没有改变原渲染，还不是 Graph 的 Noise 功能已经验证。

2026-10-01；主工程输入 1181639、包输入 e3dd725、产品 99e9207。Unity 6000.3.18f1 / URP、SG、VFX 包 17.3 / Metal / RenderGraph。无可调用 unityMCP，使用独占隔离工程 CLI；没有主工程 Assets/设置、官方包、UniversalTarget、NBPostprocess 或 Frozen 改动，没有 VFX 测试，没有 push。

最小实现边界

只改现有 NBShaderDistortionV1.hlsl 与 NBShaderForwardPass.hlsl，保留原三处 half 赋值边界。Refraction、CustomData、外部 NoiseMask、Direction/Intensity、PNoise 和屏幕 payload 保存次序不动：屏幕 RG 仍未预乘 mask，普通纹理 UV 偏移才在最后乘 mask。没有新增关键词、属性或采样。
