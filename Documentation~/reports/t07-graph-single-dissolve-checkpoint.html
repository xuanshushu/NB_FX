T07 · Graph 单贴图溶解检查点

结论：当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal / RenderGraph，在隔离 Mesh 的最终颜色与 NBPostprocess Deferred Mask 中，单贴图溶解的开关、RGBA packed 通道、阈值、指数、软宽均产生受控变化。产品 VFX Mesh 默认关闭该能力时，当前 Metal Player 构建/运行和双精确 Pass 回归通过。尚非原 NBShader 完整 Dissolve 等价；G4/G5 未放行。无可用 unityMCP，使用无可见窗口 Unity CLI；未改官方包、UniversalTarget、NBPostprocess 或主工程 Assets/ProjectSettings，未 push。

产品 Graph BaseColor 复用原 NBFX_PrepareDissolveV3 与 NBFX_ResolveDissolveV3，在 Mask 前将其 coverage 乘入 Alpha；两个自定义扭曲 Pass 仍从同一 SurfaceDescription.Alpha 取覆盖。新增 _DissolveMap（默认灰）、_Dissolve_Toggle（默认 0）、原参数向量 _Dissolve=(0.5,1,1,0.1)；原 packed 颜色通道位 10–11 复用现有 _NB_ColorChannelLo16。没有新增 keyword；原函数对软宽直接求倒数，此切片未擅改 softWidth=0 行为，实测均使用正软宽。
