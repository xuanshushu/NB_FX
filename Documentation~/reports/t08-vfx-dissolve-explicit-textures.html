T08 · VFX Mesh Output 主动溶解显式纹理复测

限定结论：隔离 VFX Output 的 DissolveMap 明确绑定受控灰色纹理、DissolveMaskMap 明确绑定白色纹理后，真正 VFX Mesh 的 Off / Single / ProcessMask 三组在当前 Unity 6000.3.18f1、VFX/URP/SG 17.3、Metal Player 均存活可见且精确双扭曲 Pass 保留。Single 与 Off、ProcessMask 与 Single 各有 87 像素差，ProcessMask 与 Off 为 0。由此修正先前“只开单图完全不可见”的观察：它依赖 VFX Output 纹理槽未赋值；显式绑定后主动功能画面响应成立。尚无 GPU 采样/Alpha 读回，不能声称达到预测的精确覆盖值 0.7157，也不是全部 VFX 功能或 G5/G6 放行。

两张仅用于隔离测试的 1×1 线性无 mip/压缩纹理：灰 (133,133,133,255) 与白 (255,255,255,255)。构建探针强制导入并核对 GUID、尺寸、像素、线性、无 mip/压缩；三份 VFX 仅 Output 两个 Toggle 与贴图槽不同，均使用 Renderer 允许的层 2/1/5。重放说明、运行探针、构建探针。
