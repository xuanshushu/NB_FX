T05/G2 · 原 NBShader GUI 状态后端

结论：仅 SyncMaterialState 后端切片在隔离工程 3/3；并非 GUI 端到端放行，G2 仍未放行。测试直接调用原 NBShaderSyncService.SyncMaterialState，不伪装成点击 Inspector、Undo、多选或序列化验证。

测试源码：Tests/Editor/G2ShaderGUIState/G2ShaderGUIStateABTests.cs，独立 Editor test asmdef 引用产品 Editor/Runtime 程序集，不改变既有 G0 Baseline asmdef。源码与受保护 Material/FeatureLevel 设置 SHA-256。Unity 6000.3.18f1 / URP 17.3，在无符号链接的 /tmp 一次性工程副本串行 EditMode batchmode；原 Editor 已退出、unityMCP 未暴露，主工程未进入测试。

  • Ultra/Mesh：packed flags（含 slot1 bit31）、Mask/Emission 关键字、主 Pass 与两个 Distort Pass、第二次同步幂等、Toggle 恢复。
  • Low CutOff → Ultra Deferred → CameraOpaque → Transparent：FeatureTier 过滤、透明混合/ZWrite、主/深度/Distort Pass、未由后端偷偷改 renderQueue=2777、每阶段幂等。
  • 两个内存材质同时同步：各自 MeshSourceMode、MaskRefine、BaseColor 和 packed bits 独立；重复同步无交叉污染。

最终 NUnit 3/3、Unity exit 0。最初 2/3 是测试夹具未开启 _NOISEMAP 父功能却期待其子关键字 _SCREEN_DISTORT_MODE；经诊断、仅修夹具后，Low tier 不允许父关键字而正确过滤，Ultra tier 双关键字允许并按 Deferred/CameraOpaque 意图选择 Pass。执行顺序与边界。

P6 交叉发现（未改策略）：这三种后端情形的日志均显示 Universal2D enabled=False 且 tierAllows(pass.universal2D)=False；当前项目和包内默认 FeatureTier Pass 集合都没有该 ID。前述 P6 真实 Renderer2D 测试是手动打开该 Pass 后通过，不能据此宣称经 NBShaderGUI 同步的 2D 材质仍可显示。用户随后以 D22 确认手动开启 Pass、保留当前主观配置；因此这是被接受的现有使用前提，不改 ProjectSettings、默认 Tier 或 Shader Pass。

未验证：NBShaderGUI.OnGUI 控件触发、Undo/Redo、真实多选 Inspector、保存/Reload 后序列化、材质改动后实际 Mesh/2D/Particle/UI GPU 结果、Player 与性能。SetUp/TearDown 对原样例 Material 和 FeatureLevel 设置文件作哈希保护，测试仅用内存克隆。
