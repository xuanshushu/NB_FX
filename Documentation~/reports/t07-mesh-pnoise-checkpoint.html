报告索引 · D24：完整 Mesh 优先

普通 Mesh 程序噪波：功能有效，严格对照 47 通过 / 93 失败

人话结论：Graph 已能生成 Simplex 与 Voronoi 程序噪波，并把它们按现有 NBShader 的顺序混入遮罩和溶解，影响普通 Mesh 的透明度；深度与投影阴影的 Alpha 路径也吃到同一结果。开关、噪波组合及 UV 来源改变时画面有明显响应，不是空图假通过。但是逐像素必须完全一样的规则下，140 项仅 47 项通过、93 项失败。失败的 Graph/现有 ShaderLab 最大单通道差为 0.00048828125；用户要求暂不追查这类低幅差异，我们保留失败而不放宽标准。本切片不能放行 G3/G4。

2026-10-01；固定产品与测试提交 94e8d7cd3518c225766031d056cd346362199efa。Unity 6000.3.18f1 / URP、Shader Graph、VFX 包 17.3 / Metal / RenderGraph；主 Agent 报告 unityMCP 不可用，故独占隔离工程用 Unity CLI 运行。本归档没有启动 Unity、修改产品/Test/官方包/Target/NBPostprocess/保护设置或推送。

测到的功能与结果

  • Forward 普通 Mesh 116 项：测试关闭、只用 Simplex、只用 Voronoi、两者并用；分别混入 Mask 或 Dissolve，含 UV0、UV0.zw、UV1、UV2、Twirl、Shared UV，正交/透视相机。23 严格通过、93 严格失败。最大 B/C 差 0.00048828125；G0 Frozen 与当前 ShaderLab 只有一项的一个像素出现 0.00006103515625 差，也原样记录。所有失败均按原测试 XML 判失败。
  • DepthOnly 12 项、ShadowCaster 12 项：前者是真实深度遮挡，后者使用实际 URP 主方向光和接收平面；各自的主画面、关闭/改变噪波对照画面，Frozen/当前与当前/Graph 均严格 0 差。两者共 24/24 通过，不等于其它深度/阴影组合全部完成。
  • 有效性控制：140 项所有已捕获整帧数值有限，启用状态的 A/B/C 重复拍摄均为 0 差；没有拍控制状态的重复帧。Forward 改动噪波的 Graph 对照至少变化 0.601806640625，至少 2,552 个中心像素明显改变。两种噪波混合方式另有 32 项直接反向对照，至少变化 0.1839599609375、2,448 个像素，因此功能响应真实存在。

测试目标为 128×128 linear RGBAHalf，中心 x/y=32..95 共 4,096 像素严格比对 RGBA；每次保存无损 float32 RGBA 原始帧和 PNG。原始 XML · 全部 140 项数值 · 原始帧 · Unity 日志。最终导入/测试日志未见 C# 或 Shader 编译错误。

“六档”不是六种算法；历史错误不是产品卡点

测试把打包的混合字段设为 0..5，但原 NBShader 共用的 BlendPNoise 实际只定义 0..3 四种行为；4/5 按原逻辑保持输入不变。Graph 保留这一协议，不能宣传“六种程序噪波混合算法”。程序噪波影响屏幕扭曲的 PN2 仍未做。

第一次 0/140 是测试夹具在渲染前按错误时点/名称检查 Pass，得到 -1，没有 raw；这不证明最终 Graph 缺 Pass。第二次 24/140 误关 SRPDefaultUnlit，116 项 Forward 不渲染；24 项深度/阴影已通过。两版夹具、日志和第二版 raw 均保留；最终版改正后才得到上述 47/93。它们不是要用户修改官方包或降低功能的决策卡点。

随后完整回归：没有新增失败，也核对了每份原始数据

同一固定产品再次运行全部 923 项：771 严格通过、152 严格失败、0 跳过。152 项恰为此前 59 项（UV 22、法线贴图 34、灯光 3）加本片 93 项，没有新出现或消失的失败。这不是只看失败名单：归档程序实际读取了 11,970 份捕获，PNG 比较完整字节，无损 raw 比较解压后的 float32 RGBA 字节和长度；以前 783 项的 9,258 份、本片 140 项的 2,712 份全部与持久旧档相同，零份不同或找不到来源。每份 SHA 和相对旧档路径列在逐文件核验清单，重复数据才不再拷贝；完整回归的 1,203 份 metrics、材质状态、生成 Preview 和 Shader 消息仍独立保留。MatCap 和 NormalMap 本轮各用独立命名空间，不再覆盖同名 back-face 目录；两组图像分别核对其原始 M0/N0 档案。
