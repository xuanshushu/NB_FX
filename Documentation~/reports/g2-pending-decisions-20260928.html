Q09 · MatCap 跨 Shader 身份的数值判据

事实：正式当前/Frozen 在渐变纹理固定点 (50,46) 为 R140/R139，严格 0 差失败；同源仅改 Shader 名称的两个独立 Shader 资产也稳定产生该 1 像素差，各自自重画为 0。故差值不能单独归因于本次 HLSL 重构，但尚未确定 Unity/Metal 导入、代码生成或数值来源。最近 Gate 复核仍见 12/13。

选择功能/维护影响验证与回退
A · 坚持跨 Shader RGBA32 每像素 0 差不改规则；G2 继续阻塞，继续定位 GPU/导入与 HLSL 数值链。保持正式夹具；若找到差异源，最小修复后全量重跑。
B · 批准建立独立标定的 MatCap 数值容差版本仅改变验收规则，不先改产品；需把不可见量化差与实质回归区分。不能直接把观测到的 1 LSB/1 像素抄成阈值。预先用同源不同名、多纹理/投影/设备重复标定，再冻结阈值；生产/Frozen 全量重跑，保留严格原始数据；若超过阈值仍失败。

建议：若业务接受感知/数值容差，选 B，但必须先独立标定；否则选 A。未答复时维持 A 的严格未通过状态，不擅自采用 B。

Q10 · Dissolve 首帧是否必须正确

事实：双 Shader 强制导入 → 正式 P4 → Dissolve下，mode0 首次当前/Frozen 1090 像素差；同一个生产 Shader 的首次→自身复画也差 1090，Frozen 自身为 0，复画后 A/B 为 0。临时预热可使随后严格循环通过，但首帧仍失败；影响可能在变体/状态/编译/Renderer 等，未定位根因。MPB 夹具另发现清缓存时首帧黑图，说明非空对照也要防止占位帧误过。

选择功能/维护影响验证与回退
A · 生产首帧必须正确不允许把测试预热当通过；G2 继续阻塞，追查根因及必要的产品修复。正式夹具不预热；新 Editor/Player、冷导入、P4 前后均复验首帧。
B · 可接受明确的产品预热协议必须设计真正运行时预热及首次可见帧保证，不能只在测试中画两次或降低断言。若需改 NBPostprocess/Renderer 合约另请批准。先证明用户可见首帧与 Player 正确，再将协议写入产品与文档；保留无预热负对照和回退方式。

建议：选 A；现有证据不足以批准 B 或把首次失败视为无关噪声。

Q11 · Universal2D 在原 NBShader FeatureTier 中的产品意图

事实：P6在隔离 Renderer2D/SpriteRenderer 中手动打开 Pass 后可见并 A/B 0；GUI 状态后端显示所有 Tier 的 pass.universal2D 均不允许，SyncMaterialState 将其关闭。包内默认 Tier 与主工程 Tier 配置均缺此 ID，原/冻结 UnLit 样例也序列化为关闭。这是 2026-06-07 已存在的配置改变（commit c99774e），不是本轮 G2 引入；提交说明未记载产品意图。当前测试仅证明 Pass 能画，不证明 Inspector 后 2D 工作流可用。

选择功能/维护影响验证与回退
A · 保持当前 Tier 策略，标记 2D 仅手动 Pass 能力不改原路径状态，G2 不把 P6 夸称为默认 2D 用户流程；产品若要求 2D 则仍有范围缺口。在 G2 文档明确限制；冻结/生产相同配置下验证无新回归。
B · 明确要求 NBShaderGUI 同步后仍支持 2D需改包内默认 Tier 及相应工程/安装配置或提供启用流程；这是产品策略变更，不是测试修补。隔离工程先验证 Sync → 保存/重导入/Undo → 真 Renderer2D → Player 变体裁剪；确认 tier/材质迁移和回退，不在用户主工程直接试改。

建议：G2 对既有行为暂按 A 记录，不私改 Tier；若本轮产品要求真实 2D 用户流程，明确选 B 后另开最小切片验证。无答复不等于批准削减或增加功能。
