Mesh TA Depth：共享 ZOffset / Override Z

本片把原 TABigBlock 的两项深度控件接入普通 Mesh Graph。ZOffset 沿用关闭时清零 factor/units 的行为；Graph 只读显示 toggle OR 非零 Offset，旧材质无需自动迁移。Override Z 通过已有 Tier 策略控制真实 _OVERRIDE_Z keyword，最后 Sync 不再绕过过滤重新开启 SV_Depth 变体。

缺 Tier 的旧 Graph 保留原能力；raw-new marker0 仍可 Validate。非法 Tier/schema 不获本片写权限。未新增 OVZ float gate、keyword、HLSL 或 pass；保留 Fresnel 第九 gate、半字修复及 DN/BackFirst 配置。验证源与集成边界。
