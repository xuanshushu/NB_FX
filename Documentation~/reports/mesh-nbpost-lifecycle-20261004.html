问题与最小修复

Controller.OnEnable 会调用 Manager.ReRegistEditorUpdate。旧方法会无条件重新订阅，即使 Manager 已禁用；取消订阅也不能保证当前编辑器分发中已经取出的回调不再执行。

原始两身份均留下 Failed：禁用瞬间 Manager 回调数为 0、效果 flags 为 0；再经过真实编辑器帧后，注册数量仍为 0，flags 却回到 17。这与当前分发中剩余回调继续执行的时序一致。旧 52 项的手动 Tick 会跳过禁用组件，未覆盖真实事件分发边界。

  • EditorUpdate 只有在 isActiveAndEnabled && !Application.isPlaying 时调用 LateUpdate。
  • ReRegistEditorUpdate 先移除旧订阅，仅在 isActiveAndEnabled 时重新订阅。

原 OnDisable 的 ResetEffect 保留。Controller、单例结构、渲染 Pass、材质属性和 NBPost 合同均未改变；测试通过实际组件启用/禁用触发生命周期，没有人工调用生产 Update / OnEnable / OnDisable。
