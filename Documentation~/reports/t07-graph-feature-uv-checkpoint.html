T07 · Graph Mask/Dissolve 独立 UV0 检查点

结论：当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal 下，产品 Graph 的 Mask/Dissolve 各自支持 UV0 旋转、纹理 ST、时间滚动的受控非零效果；默认值下既有六张 Mask/Dissolve/BaseUV PNG 逐字节不变，真正 VFX Mesh 默认值 Player 冒烟通过。只实现独立 UV0 子集，未达到完整 ShaderLab 特殊 UV/CustomData/局部旋转标志语义，G4/G5 未放行。

包内 Graph 函数在可选功能打开后使用共享 NBFX_TransformFeatureUVV2，顺序为旋转→各自贴图 ST→时间滚动；采样 helper 接收已变换 UV，避免 ST 再应用一次。控制均复用原 ShaderLab 同名参数：_MaskMapUVRotation、_MaskMapRotationSpeed、_MaskMapOffsetAnition.xy、_DissolveOffsetRotateDistort.xyz；零控制显式保留原 GetTransformedUV 表达式。未新增 keyword、Pass 或另一套公式。
