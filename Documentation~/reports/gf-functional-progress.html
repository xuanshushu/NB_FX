测试 SubTarget 保留官方 Unlit Forward Pass，并在两个新增 Pass 中仅替换最终 fragment include；测试 HLSL 固定输出 noise=(0.25,0)、intensity=0.25，由全局 _NBGFMode 隔离 CameraOpaque / Deferred。它不是完整 NBShader 功能迁移，不能作为产品 HLSL 或最终 RenderState。PlayMode 测试和它的 asmdef 使用 URP/VFX 17.3 的 Version Defines 与 Define Constraints，只验证常规程序集的依赖隔离机制。

GF-PASS强制重导入后，Graph Shader 有 10 Pass，VFX 生成 Shader 有 8 Pass；两者的精确 LightMode 均在索引 1/2，supported，ShaderUtil 消息数 0。原始结果；只证明当前版本的生成结果。
GF-VFX-SIM可重放 PlayMode UnityTest 通过：最近一次真实 VFX Asset 粒子存活 6、未剔除，帧计数 44。Test Runner 与 Console；测试源码在 测试目录。
GF-VFX-IMAGE同帧 128×128 截图：最近一次无粒子对 mode0 有 34 个像素差；mode0 对 Deferred 模式有 34 个像素差，对 CameraOpaque 模式有 26 个像素差。测试已断言三者非零。无粒子、mode0、Deferred、CameraOpaque。这是最终画面差分，尚非独立 RT/RendererList 读回，也不证明功能等价。
GF-EDITOR最终 Editor ready、非 PlayMode、编译成功；Console 当前 groundTruth 0 Error / 0 Warning。Editor、编译、Console 状态。历史 Console 留有调试探针和一次已修复 C# 名称冲突的错误，不冒充零历史错误。

未通过、未运行与依赖边界

  • 独立扰动 RT 读回未取得：Camera.Render() 返回后及 endCameraRendering 回调中，_DisturbanceMaskTex 均呈 4×4 默认 Texture2D，不是 RenderGraph 中的瞬态 Mask。不能用这些读数宣称 Mask 正确。
  • 可重放的隔离 Mesh 探针中，CameraOpaque 模式有 4096 像素画面差分，而 Deferred 差分在后续重复运行中为 0，与早先观测不一致，原因未定；基准、Deferred、CameraOpaque 图像已保留。因此 Mesh Deferred、RT 数值、原 NBPostprocess 两个 RendererList 的独立选择、合成定量正确性均未放行。
  • Player、DirectX/Vulkan、版本升级、VFX 多 Output / VAT / Mesh 输出、SRP Batcher、变体预算和旧 NBShader 回归本轮未运行；GF 不能替代后续 G3。
  • Unity asmdef/asmref 格式说明列出 asmdef 的 versionDefines / defineConstraints，但 asmref 只有目标程序集引用；因此本试验的 NBGFSubTarget.asmref 对 URP Editor 仍是无条件绑定。Version Defines 可以隔离普通 URP/VFX asmdef 代码，不能单独保证缺席 URP 时这一 internal SubTarget 扩展不参与编译。生产多管线架构需将 URP 扩展做包级隔离或明确 URP 为必需依赖，再另审；当前没有改 package.json 或安装 HDRP。

Gate 结论：包内 SubTarget 的双 Pass 结构、真实粒子和可观察画面反应已得到增量证据；GF 仍未满足 RT/合成定量与可重放跨环境要求，不启动依赖 GF 放行的产品重构。下一切片优先取得 RenderGraph 瞬态 Mask 的测试专用读回并排查 Mesh Deferred 不稳定；若需改 NBPostprocess、Target 或官方包，先交用户决策。
