项目结果证据与限度
GF-PASS强制重导入后，Graph Shader 有 10 Pass，VFX 生成 Shader 有 8 Pass；两者的精确 LightMode 均在索引 1/2，supported，ShaderUtil 消息数 0。原始结果；只证明当前版本的生成结果。
GF-VFX-SIM可重放 PlayMode UnityTest 通过：最近一次真实 VFX Asset 粒子存活 3、未剔除，帧计数 44。Test Runner 与 Console；测试源码在 测试目录。
GF-VFX-IMAGE同帧 128×128 截图：最近一次无粒子对 mode0 有 26 个像素差；mode0 对 Deferred 模式有 26 个像素差，对 CameraOpaque 模式有 24 个像素差。测试已断言三者非零。无粒子、mode0、Deferred、CameraOpaque。这是最终画面差分，还不能量化最终合成。
GF-MASK-MESH测试专用 RendererFeature 在原 NBPostprocess 之后读取 RenderGraph 全局 Mask：mode0 中心 (0,0,0,255)，Deferred 中心 (71,0,0,255)，CameraOpaque 中心再次为 0；Deferred 对基准 4096 个像素变化。Linear 项目中红 71/255 对应线性值约 0.0625，与固定向量 0.25 乘 Blend Alpha 0.25 相符。可重放脚本、原始读数、清空、Deferred、CameraOpaque；测试 Shader supported、消息 0。这是通过测试 Shader 采样 Mask 后读回的独立证据，不是直接保存瞬态 RT。
GF-MASK-VFX同一测试专用 Feature 在真实 VFX PlayMode 中读回 Mask：Deferred 对 mode0 有 26 个像素变化；CameraOpaque 对 mode0 为 0。Test Runner 已断言 Deferred 非零。清空、Deferred、CameraOpaque。结合现有 Mask Pass 只选择 NBDeferredDistortPass 的源码，可推断 VFX Output 进入该 RendererList；未独立记录 RendererList 项数。
GF-INTEGRITY测试 Feature 仅在内存中追加并于 finally 移除；RendererData 恢复 SSAO、NBPostProcess 两项，asset 未 dirty，工作树内容 SHA-256 与 HEAD 完全一致。Feature 状态、资产 hash。
GF-EDITOR最终 Editor ready、非 PlayMode、编译成功；Console 历史保留调试错误，不能声称历史零错误。Editor、编译、Console 状态。曾漏加 Core.Runtime asmdef 引用，修复后重编译成功；一次临时诊断对 Integer 属性误用 Float API 产生 2 条工具 Error，未改产品文件。

未通过、未运行与依赖边界

  • Camera.Render() 返回后及 endCameraRendering 回调中，_DisturbanceMaskTex 均呈 4×4 默认 Texture2D；故使用上述测试专用 RenderGraph Pass 在 Mask 尚有效时采样，不能把事后默认纹理当作 RT 读数。
  • 可重放的隔离 Mesh 最终画面探针中，CameraOpaque 模式有 4096 像素画面差分，但 Deferred 与基准完全相同，尽管独立 Mask 探针读到非零。这与早先一次画面差分观测不一致。基准、Deferred、CameraOpaque 已保留。最终 Uber 合成的数值/稳定性不通过，原因未定；没有改 NBPostprocess 产品代码或资产。
  • Player、DirectX/Vulkan、版本升级、VFX 多 Output / VAT / Mesh 输出、SRP Batcher、变体预算和旧 NBShader 回归本轮未运行；GF 不能替代后续 G3。
  • Unity asmdef/asmref 格式说明列出 asmdef 的 versionDefines / defineConstraints，但 asmref 只有目标程序集引用；因此本试验的 NBGFSubTarget.asmref 对 URP Editor 仍是无条件绑定。Version Defines 可以隔离普通 URP/VFX asmdef 代码，不能单独保证缺席 URP 时这一 internal SubTarget 扩展不参与编译。生产多管线架构需将 URP 扩展做包级隔离或明确 URP 为必需依赖，再另审；当前没有改 package.json 或安装 HDRP。

Gate 结论：包内 SubTarget 的双 Pass 结构、真实粒子、Mesh/VFX 的 Deferred Mask 和 CameraOpaque 画面反应已取得证据；但最终 Uber 合成在受控 Mesh 场景未稳定复现，且 Player 未运行，GF 仍未放行。下一步只读/测试侧归因该差异；若确认必须改 NBPostprocess、Target 或官方包，立即停止受影响实现并交用户决策，不自行修补。
