T07 · Graph Mask2/Mask3 纹理子路径检查点

结论：当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal，产品 Graph 在原单层 Mask 之后增加可选的 Mask2/Mask3 纹理层：按原 ShaderLab 顺序将三层通道值相乘，再统一调用共享 NBFX_ResolveMaskCoverageV3。受控 Mesh 中单开/叠加、R/A 通道、各自旋转/ST/时间滚动均引起画面变化；默认关闭时先前六张 PNG 逐字节不变。仅为三层遮罩的纹理子路径，不含 Gradient/Noise 等完整 Mask 功能，G4/G5 未放行。

新增原 ShaderLab 同名 _MaskMap2/_MaskMap3（白图默认）、_Mask2_Toggle/_Mask3_Toggle（默认 0）及 _MaskMap3OffsetAnition。复用 _MaskMapVec.y/z 旋转、_MaskMapOffsetAnition.zw 与 _MaskMap3OffsetAnition.xy 滚动。各层只在主 Mask 和本层 Toggle 同开时采样；ColorChannel bits4–5/6–7 控制其通道。未新增 keyword、Pass 或并行算术核。
