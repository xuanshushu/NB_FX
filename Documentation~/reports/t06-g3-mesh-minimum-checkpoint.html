T06/G3 · 产品 Graph 的 Mesh 最小链路

结论：最小 Mesh 链路已在当前 URP/Metal 的 Editor 批处理和 StandaloneOSX Player 跑出双扭曲最终画面，并在 Editor 读到 Deferred Mask；G3 尚未放行。2026-09-30，Unity 6000.3.18f1、URP/Shader Graph/VFX Graph 17.3.0，Metal，URP-HighFidelity、RenderGraph。当前工具列表没有可用的 unityMCP，因此主 Agent 仅使用不打开可见窗口的 Unity CLI 和隔离工程。没有修改官方包、UniversalTarget、NBPostprocess、主工程 Assets/ProjectSettings；未 push。

产品候选位于 NBShaderGraph.shadergraph：只激活 URP Target，m_SupportVFX=true；File Custom Function 经 NBGraphBaseColor.hlsl 调用现有 NBFX_ComposeBaseColorV1。包内 UniversalSubTarget 仍由 .asmref 编入当前 URP Editor 程序集，不改官方源码；两条测试之外的产品 Pass 调用 NBFX_BuildDistortionPayloadV1，并固定使用与原扭曲 Pass 相同的源 Alpha 混合，而不继承 Graph Forward 的 Blend。该 internal API 耦合只承诺当前安装版本，URP 缺席时的安装隔离留待 T10。

在隔离克隆中把可重放探针源码暂放入 Assets/Editor，执行 Unity -batchmode -quit -executeMethod NBFXT06BatchRenderProbe.Run。探针强制重导入产品 Graph、内存创建 128×128 渐变背景/半透明 Mesh/相机，以材质 _NB_DistortionMode 选择 0、1、2；原 NBPostprocess 保持活跃。为读取瞬态 Mask，仅在内存中临时追加测试 RendererFeature，渲染后在 finally 移除。前景透明关键词、Blend、Alpha 均显式设置，避免把不透明白块误判为 CameraOpaque 失败。
