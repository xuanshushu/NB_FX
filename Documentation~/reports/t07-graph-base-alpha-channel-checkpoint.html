T07 · Graph 主纹理 Alpha 通道选择检查点

限定结论：产品 Graph 使用原共享 packed color-channel 字的最低两位选择 BaseMap 的 R/G/B/A 作为 Alpha 源，默认值改为原 ShaderLab 的 3（A），而不新增 keyword 或独立 flag；现有 Graph Sample A 端口仍保留序列化连线，但 HLSL 以 packed 选择为准。当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal 隔离 Mesh 用受控 RGBA=(64,128,192,224) 输入、Flags0 bit29 将 Alpha 反映到 RGB 时，四通道中心红值依次 71/99/120/129；关闭 bit29 后 R/A 两种选择的最终 RGB 差 0。限定功能成立，不等于原 ShaderLab 完整 B/C 或 G4/G5 放行。
