T08 · 真正 VFX Mesh 的基础色主动值

限定结论：Unity 6000.3.18f1、URP/SG/VFX 17.3、Metal 隔离 StandaloneOSX Player 中，四个真正的单粒子 Output Particle Shader Graph Mesh 使用显式线性 RGBA=(64,128,160,192) BaseMap。A0/A1/A2 仅把 Output 的 Timeline RGB 强度设为 0/1/2，最终颜色按预期近似线性增加；R0 仅把 BaseMap Alpha 选择从 A 改为 R，在源 RGB 强度同为 0 时得到显著不同的透明覆盖。四者生成的两个自定义 LightMode 均存在，运行时索引均为 1/2，冻结重复读回差 0。这个切片证明主动 Output 值在当前环境生效，不等于原 ShaderLab 全功能或 G4/G5/G6 放行。
