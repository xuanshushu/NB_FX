普通 Mesh 八类贴图的独立高级 UV

人话结论：遮罩 1/2/3、叠加贴图 1/2、颜色 Ramp、溶解及溶解遮罩，现在都能独立选择 UV 通道、Twirl 或共享 UV。它们不会错误地继承主纹理的缩放和偏移。96 项对照中，77 项完全一致，19 项因少量像素的微差未达到严格 0 差；最大通道差约为 0–1 范围的 0.098%。按用户要求只记录，不继续追查微差，不改通过标准。当前仍在普通 Mesh 阶段，没有进入新的 VFX 验证。

测试跨 2026-09-30 晚至 2026-10-01 凌晨。主工程输入 55697fe，包输入 d8e772b，产品 9e2455d；主工程输入 gitlink 当时仍为 4358856，后续由主 Agent 集成指针，不把未推送的包提交冒充远端。Unity 6000.3.18f1 / URP、SG、VFX 包 17.3 / Metal / RenderGraph；无可调用 unityMCP，用独占隔离 clone 的 CLI。原 ShaderLab、官方包、UniversalTarget、NBPostprocess 和主工程保护资产在本片不改。

本片做了什么

  • 在现有 NBGraphBaseUV 中，从同一次共享 NBFX_BuildBaseUVsV1 的 BaseUVs，按原 UVModeFlag0/Type0 位置 2/4/6/12/14/16/18/26 取八路独立源，连到现有颜色函数的八个 UV 槽。保留全部旧输入/Out，只追加输出。
  • 各功能仍在颜色函数内独立执行原有旋转 → 自身 ST → 滚动速度 → 采样，没有第二次 ST，没有把八路接到 MainTexUV。DissolveRamp 的 U 来自溶解数值，不当作普通 UV 路由。
  • 限定模式 0/1/2/8：UV0、特殊 UV、Twirl/Polar 源、共享 UV。本矩阵测试 UV0.xy、UV0.zw、UV1/UV2、Twirl、Shared→UV2；不是各功能 Polar 的全组合验收。非均匀纹理、不同 float4 UV0/1/2、自身非 identity ST；特殊 UV2 例另有静态 17° 旋转，速度均为 0。
  • CustomData、位置/屏幕/圆柱宿主源、Noise、时间动画、UI/Flipbook、half 精度和 VFX 仍不由本片宣称支持。Support VFX 设置保留，没有新 keyword 或 packed 位重定义。
