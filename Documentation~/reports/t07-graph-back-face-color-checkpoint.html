T07 · Graph 背面基础色检查点

限定结论：产品提交 38c114d，以包内 Graph 的标准 Is Front Face 节点，把原 ShaderLab 同名 HDR 属性 _BaseBackColor 和原 Flags0 bit28 接入现有共享 NBFX_ComposeBaseColorV1 的 effective tint 输入；不开 flag 时不影响基础色，开 flag 时只把背面 tint 换成背面颜色。无新 keyword/Pass，未修改原 ShaderLab、官方包、UniversalTarget 或 NBPostprocess。当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal 隔离 Mesh 的受控 Quad 对照支持该限定行为，但不等于完整背面渲染次序、原 ShaderLab B/C 或 G4/G5 放行。
