具体测了什么

22 种设置分别用正交和透视相机拍摄，共 44 项。对象是曲面普通 Mesh，包含背面、非均匀缩放和负缩放；法线贴图的 UV0、UV0.zw、UV1、UV2、Shared UV、Twirl/Polar、四种 Wrap、自动/强制 LOD、强度与 mask 模式；只观察 Fresnel、MatCap 或两者。A 为 G0 Frozen ShaderLab，B 为当前 ShaderLab，C 为实际生成的 Graph。测试对主设置和一个有意改变的对照设置分别拍摄，并重复拍摄。

  • A/B 原实现保护：44 项主画面与对照画面在 64×64 内部区域严格 RGBA 0 差，说明本次纯共享法线解码抽取没有改变已测 ShaderLab 数值。
  • B/C Graph 对照：10 项主画面及对照均严格 0 差；34 项至少一个画面非零，XML 如实判失败，Unity 测试退出码为 2。主画面及对照的最大单通道差值均不超过 0.0029296875，但有的对照画面多达 2999/4096 个像素非零，不能描述为“只差几个点”。没有调高容差或改写失败为通过。
  • 有效性控制：所有原始帧全帧数值有限，重复画面 0 差；每项改变设置后至少有 1831 个内部像素发生大于 0.01 的变化，最大通道变化至少 0.063720703125，因此不是空白图的假对照。

目标为 128×128 linear RGBAHalf，严格区域 x/y=32..95；无损 float32 RGBA 原始帧和 PNG 全部保存。初次导入退出码为 0，导入/测试日志未见 C# 或 Shader 编译错误。四次预热只证明稳定帧，不证明冷首帧或全帧逐像素等价。
