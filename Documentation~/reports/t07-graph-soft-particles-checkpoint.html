URP Graph Soft Particles：Mesh Alpha B/C 与真正 VFX 单粒子深度对照

限定结论：包提交 ee1856b 将原 ShaderLab 的软粒子深度淡出算术抽成共享函数，Graph 新增 _SoftParticlesEnabled、_SoftParticleFadeParams，采样相机深度并按当前像素眼深度衰减 Alpha。隔离 Mesh 的 8 组 Graph/原 ShaderLab Alpha 每像素严格 0 差；真正 VFX Mesh Output 在 Metal Player 的有/无不透明背板对照中，仅开启软粒子时对背板深度有响应。这是单功能、单粒子、当前 URP 环境的切片，不放行 G4/G5/G6，也不代表无深度纹理成本。

部署边界与未验证项

Graph 直接采样 _CameraDepthTexture，不会自动替相机声明 REQUIRE_DEPTH_TEXTURE；测试明确开启 URP Camera 的 requiresDepthTexture。主工程三个 URP Asset 当前 m_RequireDepthTexture: 0；实际使用者必须配置相机/Renderer 提供深度，并承担对应预通道或拷贝成本。若没有有效深度，不能从本测试推断软粒子可用。

未覆盖多粒子、粒子深度排序、深度纹理不可用的相机、MSAA/动态分辨率/XR、移动端、多个 Renderer、Inspector 保存/重导入、Depth Decal/场景深度其它效果、性能与全量 ShaderLab 组合。克隆中的测试资产/脚本已由主 Agent 清理，清理后 Unity CLI 编译成功退出且无 error CS/Shader error；三项受保护设置哈希稳定为主 Agent 核对，具体哈希值未随日志归档。完整附件和重放步骤见 README及 SHA-256 清单。
