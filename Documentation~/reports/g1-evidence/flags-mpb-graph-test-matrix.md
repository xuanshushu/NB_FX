## Gate cautions

- **Static arithmetic is not Unity behavior.** The 728 modeled vectors prove only bit layout arithmetic and source-level decoder/writer agreement. `Material`, serialization, HLSL compiler, GPU sampler, SRP Batcher and VFX particle payload are unrun in this T01 work.
- **Do not reuse GF as product parity evidence.** The GF graph/pass is intentionally limited to custom LightMode feasibility.
- **Serialized compatibility is real:** 38 sample `.mat` files under `Assets/NBShaderSamples` contain flags0/1/channel; six have nonzero Wrap, four nonzero UV low, two nonzero UV type. `flag_protocol_inventory.json` records exact counts/values. This is read-only investigation, not a change request under `Assets`.
- **Invalid direct API input:** `SetUVMode(UnknownOrMixed=-1)` and `SetColorChanel(UnKnownOrMixedValue=4)` are not guarded and could spill into neighboring bits; UI choices are bounded. Treat setters as requiring 0..8 and 0..3, respectively, until a separately reviewed fix exists (`NBShaderFlags.cs:661-679,731-751`; `NBShaderProtocolItems.cs:242-259,897-908,1019-1038`).
