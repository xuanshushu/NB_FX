T08 · 真正 VFX Mesh Output 主动溶解参数 C/D

限定结论：在当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal 的隔离 Player 中，同一产品 Graph 的三个真实 Output Particle Shader Graph Mesh 变体仅改变 Output 端口 _Dissolve_Toggle/_DissolveMask_Toggle。三个系统均 alive=2、未裁剪且保留运行时双自定义 Pass；关闭/单图开启/再开过程遮罩的画面分别是可见 100/不可见 0/可见 100 像素，关和过程遮罩 PNG 逐字节相同。生成 shader 确有 0/1 端口值，说明主动端口对渲染有作用；但单图结果未达到预先推算的约 0.5 透明度，因此不能宣称 VFX Dissolve 数值等价、所有默认纹理绑定正确或 G5/G6 通过。

测试只创建三份Off/Single/ProcessMask隔离变体，Output 序列化端口差为 0→1；全在 Renderer 允许的 layer 2/1/5，不重犯layer 3 排除问题。预测来自共享 Dissolve V3：灰图与默认阈值 0.5 时单图覆盖约 0.5，白遮罩过程模式接近 1；实际单图完全不可见。导入的隐藏 VFX Material 记录为透明、_SrcBlend=5/_DstBlend=10、AlphaClip 0，但 _DissolveMap/_DissolveMaskMap 对 Material API 均为 null；shader 属性声明默认 grey/white。实际采样值或片元丢弃原因未读回，保持待查。
