URP Graph Depth Outline：先完成普通 Mesh 对照

限定结论：包内产品代码提交 6f51533 把原 ShaderLab Depth Outline 的颜色/Alpha 合成抽为共享函数，Graph 新增 _DepthOutline_Toggle、_DepthOutline_Color、_DepthOutline_Vec。在当前 URP/Metal 隔离夹具，普通 Mesh 的 8 组 Graph ↔ 原 ShaderLab 全画面 Alpha 每像素 0 差；原 ShaderLab 共享函数抽取前后另有 8 组 全 RGBA 每像素 0 差。这是 Depth Outline 子功能的 T07/G4 候选证据，不等于 Mesh 全功能等价，也不放行 G3/G4。

阶段归属（D24）：先补齐 T06/G3 的普通 Mesh 最小路径，再做 T07/G4 普通 Mesh 完整功能与 GUI；只有通过前两阶段的相应审核，才正式进入 T08/G5 的 VFX。本文后半的真正 VFX Player 结果是此前提前探索的历史事实，只保留可重放原始证据，不计作 T08 推进、G5 放行或普通 Mesh 完成的替代品。

部署边界、失败项和未运行项

Graph Depth Outline 通过 URP 场景深度纹理实现；这些夹具把相机 requiresDepthTexture 明确设为 true，尚未验证不提供深度纹理的实际场景。主工程三个 URP Asset 的默认深度请求为关闭；该测试不能证明开箱生效，也未测额外深度预通道/拷贝成本。原 ShaderLab/Graph 的全部 RGB 严格等价并未证明，已观察到非描边区 G 相差 1/255；这属于当前夹具的颜色输入编码差异，不把它归因于 Depth Outline 算术。生成 Shader、构建、Player 是提前探索，不代替 T06/G3、T07/G4 的 Mesh 全功能矩阵。未运行多效果组合、Depth Decal、缺失深度、动态分辨率/XR、性能、材质 Inspector/保存重导入、状态/Pass/后处理完整组合、首帧与最终人工检查。G2 的 MatCap 微差与 Dissolve 首帧按 D23 另行保留，不借本测试改写。

原始附件、输入与重放边界见 README 和 SHA-256 清单。主 Agent 已清理隔离克隆中的 Outline 测试资产、探针及 pre-outline Shader/HLSL；清理后 CLI 导入/编译退出 0，无 error CS/Shader error。三项受保护设置哈希未变；没有在清理时新增 VFX 测试。本报告不申请任何 Gate 放行。
