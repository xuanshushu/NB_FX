T05/G2 · MatCap 场景顺序与数值链检查点

结论：找到了差值在 MatCap 采样及合成中如何传到最终像素，但没有找到可证明保持原效果的产品修复。正式严格测试仍失败，G2 不放行。本轮只在隔离工程临时改诊断夹具及两份 HLSL，结束后恢复；正式产品 Shader、冻结基线、测试判据、NBPostprocess、官方包和 Tier 配置均未改。没有 push。Unity MCP 在本会话未暴露；主要用 Unity 6000.3.18f1 / URP 17.3.0 / Apple M3 Pro Metal 的无界面 -batchmode -quit 串行执行，不要求用户值守 Editor。

给使用者的解释

对同一个 96×96 画面，当前 Shader 和冻结 Shader 只有坐标 (50,46) 的最终红色数字不同：140 与 139，其他通道相同。它不是整张图“亮了 1/256”。更高精度的临时测量显示：这个位置从 MatCap 纹理取出的红值约为 0.08913309 与 0.08888889，差 0.00024420；经过该用例的红色权重 0.9 后，最终线性红值约差 0.00021976。写成 8 位颜色时，恰好落在相邻两个整数上。因此肉眼很难发现，严格“所有像素完全一样”的测试仍必须报失败。这里的浮点数与 8 位读回走不同格式/转换，不应直接用 140/255 去等同 0.260219783。

正式失败与场景条件

当前正式测试 G2MatCapABTests.MatCapViewUVAndBlendMatchFrozenWithVisibleControls 的判据未改。主工程在 VFX 样例场景活动时，即使双 Shader 强制重导入仍稳定看到 (50,46) R140/R139；当前侧、冻结侧各自复画为 0 差，跨侧复画仍为 1 差。原样例场景或空场景活动时，某些测试顺序可通过；同时载入原样例与 VFX 场景亦可通过。这说明渲染上下文/顺序会影响这一个比较，不能把一次通过当成问题消失。场景和根对象矩阵、正式主工程失败留原始记录。

隔离场景里，关闭 Main Camera 或将它的 culling mask 设为 0，以及关闭 SamplesRoot，均可使该次直接严格测试通过；只留 Lighting 或 tyVAT 子组会失败，只留另三个子组各自通过。这里证明的是“先前场景相机绘制是触发条件之一”，不能证明具体哪个材质、某个特效功能或 GPU 内部状态就是根因。根对象及子组原始 JSON 逐项列在矩阵，例如关闭 Main Camera及只留 Lighting。结束时主工程样例场景恢复、dirty=false、Console Error 0，随后关闭交互 Editor；本轮提交不含场景变更。

隔离副本的无界面批处理在打开 VFX 场景、强制导入两 Shader、显式绘制其 Main Camera 后，原正式夹具首测和立即复测均为同一个 1 像素差：恢复原文件后的结果。相反，没有显式场景相机绘制的首轮批处理先出现 2112 像素的“无 MatCap 对照”冷态差，立即复测才通过；这是另一个冷态现象，未拿它来标定 MatCap 容差，也未用复测通过放行 Gate。见首轮和复测。

临时诊断：差值出现在哪一步

以下只是隔离副本诊断：同一临时夹具对 MatCap 渐变纹理正交投影、加法模式、opacity 1 采集 ARGB32 与 ARGBFloat；每阶段在当前与 Frozen 两份 HLSL 的相应位置插入同样的提前输出，跑完立即恢复。诊断夹具在无 MatCap 对照前增加三次预捕获，避免把批处理冷态 2112 像素混作本次采样差。它不是正式 G2 测试。准确插入点、可重放步骤、执行脚本和输入 hash 见阶段编辑、重放、SHA-256、批处理脚本和诊断夹具。

“只输出采样结果”的临时阶段使诊断测试随后在“加法/乘法应不同”的既有功能断言失败，这是提前输出绕过合成的预期副作用；这里只采信到该断言之前已保存的采样数值，不把整个阶段记作测试通过。另试过只把临时测试纹理的 Texture2D.filterMode 改成 Point，结果不变；Shader 明确向 SampleTexture2D 传 sampler_linear_clamp，所以这个实验不能证明 Point 采样是否有用，不能作为修复建议。此前同源只改 Shader 名称也会产生同一个严格差值；本轮证据仍不支持把它直接归罪于本次重构。

审核与下一步边界

七轮批处理日志均无 C# 编译错误或 Shader error 标记，Unity 进程退出码 0；日志核对。临时测试、HLSL 和 batch 脚本在隔离副本已恢复/删除，恢复后的正式夹具仍失败；输入 SHA-256 与正式工程一致。本次不改变 Q09 的严格 0 差规则，也不把“画面看不出”当通过。若继续定位，需要以当前 VFX 场景绘制作为固定触发前提，进一步验证 UV 微差与 Shader 身份/编译产物的关系；任何容差改动要另有事先规则和批准。Dissolve 首帧及 G2 其他缺口独立存在。本检查点只归档证据，不放行 G2/G3。
