推断边界：“只改名称”仍是两个导入、编译、GPU 程序与材质实例，可能涉及 Unity/Metal 代码生成、变体或浮点采样/量化；本试验不能指出其中哪一步造成差值，也不能证明生产与 Frozen 的所有 MatCap 差异都与重构无关。先前 Float RT 在该点约 0.0002197623，渐变纹理才触发，详见前次诊断。它只证明“1 像素差 ⇒ 重构回归”这一归因不成立，且跨 Shader 资产 RGBA32 bit-exact 在当前受控输入上已有同源反例。

2026-09-29 补证：隔离场景顺序与 MatCap 数值阶段把正式差值追到渐变纹理采样结果：该点红色浮点采样约差 0.000244，经过 0.9 权重后约差 0.000220，最终落在 R140/R139。它仍未证明 Shader 身份以何种 GPU/编译机制产生微差，未改变严格测试结论。

需要用户选择的 Gate 规则：现有G2 与容差约定禁止在看到失败后由实现者自行放宽判据。可继续坚持跨 Shader 身份逐像素 0 差并追查 GPU 代码生成（G2 维持阻塞）；或者批准另立验证版本，以同源不同名对照和多次/多输入标定后预先确定 MatCap 数值容差，再重跑生产/冻结和所有正负控制。不得直接把本次观测到的“1 像素、1 LSB”抄成通过阈值。无论选择何种规则，Dissolve 冷态 1090 像素问题仍需独立解决。
