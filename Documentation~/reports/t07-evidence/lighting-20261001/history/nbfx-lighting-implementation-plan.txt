L0 ordinary Mesh lighting candidate — bounded, not final equivalence.
Source: NBShaderForwardPass.hlsl 667-773, NBShaderInput.hlsl 1385-1453, current NBGraphBaseColor.hlsl, local URP 17.3 / ShaderGraph 17.3 sources.
1. Shared math: call URP UniversalFragmentBlinnPhong/PBR and package SixWaySmokeLit UniversalFragmentHalfLambert at existing post-early-adjust/pre-MatCap stage. Runtime _FxLightMode 0/1/2/3, no new material-mode keywords. SixWay=4 unsupported pending L1; do not map to Lambert.
2. Real InputData for L0: world position from SG Position(World); faced N0 normal (once); normalized view from SG ViewDirection(World); per-fragment main shadow coord via TransformWorldToShadowCoord; default per-pixel SampleSH(normalWS) (same as old SampleSHPixel with no EVALUATE_SH_*); normalized screen position from SG Default Screen Position; shadowMask from SAMPLE_SHADOWMASK(0) when no LIGHTMAP_ON (unity_ProbesOcclusion); metallic/smoothness normal mask weights from N0's one sample and _MaterialInfo; normalTS from same N0 decode. Additive pixel light via URP function; no dummy stock Unlit InputData.
3. Scope exclusions: static/dynamic lightmaps, APV, screen irradiance, EVALUATE_SH_VERTEX/MIXED, vertex additional lights, interpolated shadow coords and SixWay. They are later L1, not a final feature reduction; no VFX or Player claims. Main shadows may have edge differences because L0 computes fragment coord where legacy can interpolate; raw differences reported, not misrepresented as pass. SH default is exact function. Reflection-probe blend/atlas and Forward+ are separately unverified.
4. SubTarget local cloned Forward KeywordCollection (do not mutate built-in shared): append URP CoreKeywordDescriptors MainLightShadows 4, AdditionalLights 3, AdditionalLightShadows 2, ShadowsSoft 5. Upper bound 120 gross combinations per previous Forward combination, subject to URP stripping. AdditionalLights Vertex variant exists but is explicitly L1-unimplemented; tests must set URP asset per-pixel. Extra URP axes such as ClusterLightLoop, LightCookies, ReflectionProbe*, LightLayers are not yet enabled; keep untested in L1. Actual compiler variant counts, stripping, Player size not validated.
5. Strong tests: A Frozen/B Current/C Graph, orthographic/perspective, main front/back and all 3 lit modes plus unlit, ambient SH two distinct probe colors on the same normal, main shadow cast on/off, one additional pixel light on/off, normal-map mask weights. EarlyColorAdjust/MatCap/Emission order is structurally inspected in the candidate but not tested by the initial 8 fixture cases; add separate interaction tests before final parity claims. Each state must have strong B and C counterfactual deltas, repeat raw RGBA and finite, strict B/C zero by default; report any known microdelta without concealing. Render only an unsaved additive EmptyScene (PreviewScene cannot be active for per-scene SH), then restore prior active Scene and close it; in-memory material/RT; no persistent settings/URP asset mutation.
6. Stop if official package/UniversalTarget/NBPostprocess edit becomes genuinely necessary; current local APIs suggest no such blocker. Graph function stage ports + package SubTarget suffice for L0, not final full parity.
