FIXTURE COVERAGE / COUNTERFACTUAL LOGIC
* TestCaseSource is 3 routes x 2 cameras x 3 IOR values (18) plus 3 routes
  x normal/backface/PN/TIR (12) = 30 NUnit cases. Frozen A is a material
  made from FrozenPath, not current ShaderLab; B uses LegacyPath, C GraphPath.
  Main/texture-mode/mask1 A/B and B/C use strict ROI zero, IOR control B/C
  also strict zero. B/C repeats and ignored NoiseMap/no-NOISE gates compare
  entire raw frames to strict zero. Finite checks cover all captures.
* The quad's Y65-degree TIR case with IOR=.65 gives eta~1.538 and center
  normal-incidence cosine~.423; k=1-eta²(1-cos²)<0, so the original helper
  intentionally returns zero. The orthographic IOR1 flat case likewise
  returns the incident -Z direction with zero projected XY. These are
  legitimate NO-OP primary refraction outputs, not missing pass evidence.
  An unconditional >100 visible-primary-pixel guard is therefore wrong for
  Opaque (and possibly Forward) in those two cases. Root is changing the
  guard to require >100 visible pixels in the nonzero texture-mode / other-
  IOR counterfactual instead, while keeping zero primary-offset expectations,
  B/C strict-zero, IOR/on-off causal response and actual image metrics.
* The existing mask-causality exception for Forward/Opaque IOR1 orthographic
  flat and TIR is logically sound: no offset means changing the external
  mask need not change visible color. Deferred is different: its encoded
  blue/alpha coverage responds to mask even when signed RG is zero, so its
  mask response requirement is meaningful. There is no need to relax image
  zero-difference assertions or the overall finite/repeat checks.
* Requiring onOff>0.005 in zero-offset cases is not intrinsically wrong:
  its OFF control changes to the deliberately nonzero texture Noise source,
  not merely toggles the mask. Requiring IOR-difference is also meaningful:
  TIR/.65 versus 1.5, or IOR1 versus 1.5, creates a nonzero counterfactual.
  Actual GPU values/visibility remain to be checked by the root's serial
  Unity validation, not asserted as a result by this review.
* The test uses 1x1 noise textures with strongly different RG/alpha, a
  nonuniform BaseMap/background, explicit mask/normal/PNoise controls,
  exact named pass selection and a renderer-mask read. It does not mutate
  renderer asset on disk; its finally block checks bytes. Normal and
  backface cases are orthographic only; curved geometry, all UVs, VFX,
  Player and invalid material intent states are outside this RF1 matrix.
