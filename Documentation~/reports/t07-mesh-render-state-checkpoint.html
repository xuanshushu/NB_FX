普通 Mesh 颜色写入与 Stencil

人话结论：Graph 现在可以像原 NBShader 一样，指定只写入某些颜色通道，并按 Stencil 遮罩决定哪些区域显示。正交和透视相机共 30 项对照全部完全一致。这里验证的是普通前向渲染，不代表阴影、深度、扭曲 Pass 和所有高级状态均已完成。

2026-10-01；主工程输入 b2c3972，包输入 3298834，产品 90d7bc6。Unity 6000.3.18f1 / URP、SG、VFX 包 17.3 / Metal / RenderGraph。unityMCP 无可调用工具，使用独占隔离 clone CLI；主工程 Assets/ProjectSettings、官方包、UniversalTarget、NBPostprocess 未改。此轮未运行真正 VFX。

实现与边界

  • 包内 SubTarget 复用原名称和默认值，增加隐藏的 ColorMask 和七项 Stencil 状态属性；它们仅供 ShaderLab 渲染状态引用，不额外重复声明 HLSL uniform。
  • 先复制 URP 的 RenderStateCollection，再追加状态，未修改官方共享集合。Forward 与两个 NB Pass 使用材质 ColorMask/Stencil；相关 Depth/Shadow 等 Pass 加 Stencil，同时保留它们原有 ColorMask（DepthOnly R、ShadowCaster 0）。本片只实际绘制 Forward。
  • 数字 ColorMask 的对应关系是 R=8、G=4、B=2、A=1。测试背景不是全黑，RGBA 各不相同，能辨别“没有写入”而非误判看不见为一致。
