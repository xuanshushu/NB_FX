T05/G2 · ShaderFlags1 bit31 / MaterialPropertyBlock GPU 对照

结论：稳态隔离工程通过，冷态不能放行；G2 仍未放行。原 ShaderLab 与 G0 Frozen 在五种状态下的稳态 GPU A/B 均为 0 差异，且整个 packed word 种子 + bit31 的 MPB 路径与 Material 全字写入同图。首次冷态 A/B 失败和清 ShaderCache 后首帧黑图，禁止将后续通过倒填为首次冷态通过。

测试源码：Tests/Editor/G2ShaderFlagMPBABTests.cs，源码、原/冻结材质与主工程 QualitySettings SHA-256。环境：Unity 6000.3.18f1、URP 17.3、Metal、EditMode；原 Editor 退出且 unityMCP 未暴露，主 Agent 串行用无符号链接的 /tmp 一次性工程副本批处理；主工程未运行或修改 ProjectSettings。
