中间失败、隔离与未覆盖项

样例场景的 Controller 曾把 NBPostprocess Flag 设为 113，导致未隔离的 Editor Camera.Render() Mesh 探针 Deferred 画面差分为 0；另一次临时脚本对 Integer 属性误用 Float API 产生两条工具 Error。中间报告保留这些原始观测，没有删除历史。后续使用无 Controller 的包内 Player 场景与序列化透明材质重复了 Mesh/VFX 最终画面测试；不据此推断原样例所有后处理组合已回归。

未覆盖：完整 NB 功能 HLSL/GUI/RenderState、SRP Batcher、关键词/变体预算、原 NBShader 回归、VFX Mesh/VAT/多 Output、Compatibility Mode、DirectX/Vulkan、HDRP、Unity 6.5 和性能。.asmref 对 URP Editor 程序集的绑定无条件，普通 asmdef 的 Version Defines / Define Constraints 不能让其自动变为可选；当前只证实 URP/VFX 都安装时的功能可行性。HDRP-only 导入及包级拆分列为 Q08，不能从 GF 推断已解决。

Gate 决定与回退

GF 放行，范围限定为当前 URP 17.3 / Metal 的 Pass 功能可行性。允许 T01 吸收双 Pass 接口、RT 数据契约与版本隔离风险；T02–T05 仍须等 G1。T06/G3 在真实共享 HLSL、产品候选 Graph/材质与 Renderer 状态上独立重测，不继承本测试固定数据的通过结论。测试切片可由对应 Git commit 回退，未 push。
