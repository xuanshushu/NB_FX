报告索引 · D24：普通 Mesh 优先 · 前一片 POM1

普通 Mesh 色散已接入；58 项中 47 项严格通过、11 项仍失败

人话结论：色散会把红、绿、蓝分开取样，形成颜色错位。包内 Graph 现已在普通 Mesh 的 Forward 与两条 NB 扭曲 Pass 使用和当前 NBShader 同序的色散计算。实测功能开启后有非零画面响应；Frozen A 与当前 Shader B 的开、关图像严格相同，重复帧也严格相同。但 Graph C 与 B 的10 项还有少量像素差，另 1 项是屏幕折射辅助“变化必须大于 0.003”断言未达标；所以绝不写成 58 项全过或 G3/G4 放行。

固定产品与最终测试源码提交 666dfeadf219d074dfaa2b92c77319dbe4e09028，8 路径无损源码与 SHA。只做包内实现：原 ShaderLab Pass 标签、官方 URP/Shader Graph/Target、NBPostprocess 与 packed 协议未改。主 Agent 独占 Unity 验证与 Git；本档案仅复制、核查固定源码和原始证据，没有运行 Unity、改产品或 push。

正式证据：两个独立串行进程，而非一份 58 项 XML

v3 的 56 项：46 通过 / 10 严格失败；v4 的 POM 两项：1 通过 / 1 严格失败。两批算术合计 58 项，47 通过、11 失败、0 跳过。这是两个独立 Unity 测试进程，不能称为“单进程 58 项通过”。v4 只在测试的 OneTimeSetUp 增加生成 Shader 源码导出；用例输入和断言与 v3 相同，逐行差异可查。56 项原 XML · 2 项原 XML · 完整统计与失败身份。

两批 58 份指标、920 张 PNG 和 920 份压缩的整帧 float32 RGBA 原值均留存，原日志也无损压缩留存。全部画面有限；A/B 开启与关闭严格 0 差；A/B/C 重复严格 0 差。B/C 主画面或关闭控制的最大通道差 0.00048828125，仍按原来的严格 0 差规则判失败，未改容差。10 项 B/C 微差保持原始失败；另外 NBCameraOpaqueDistortPass_refraction_ortho 的主 B/C 为 0，失败的是额外正对照：要求响应 >0.003，实得 0.002197265625。不能把这项描述成 B/C 不等。主 Agent 原始统计 · 56 项原始帧 · POM 两项原始帧。

额外的 CameraOpaque 16 个跨 UV 边界 Clamp/Wrap 与 LOD0 控制均严格 0 差，且把 UV 额外移 1 圈会引起非零画面变化；这避免了用常量纹理或没跨边界的图来“证明”钳制。Forward、CameraOpaque 和 Deferred 的生成 Pass 宏位置均由实际生成 Shader 审计记录；生成源码不等于 VFX 或 Player 验证。固定相机为当前 Metal/Unity 6000.3.18f1 的 128×128 线性 RGBAHalf RT、ROI (40..87)，不能推广到所有分辨率或平台。

历史失效与证据缺口如实保留

最初尝试把 58 项放在一个进程里跑，原 XML 为 5 通过 / 53 失败，但有 POM 首帧/重复帧空白，原因尚未证实，不能作为色散回归结论；该轮原 XML、日志、截图及 float32 帧仍独立保留。首次 POM 两项重跑的 1/1 原始证据也保留。

另有一个确实运行过的 v2 剩余 56 项：当时观察到 26 通过 / 30 失败，但主 Agent 重用相同临时输出路径时，把这轮的 XML、日志和捕获帧覆盖了。它们已经无法恢复；只有v2 测试源码与当时记录的汇总幸存。此处明确承认证据处理错误，绝不把 v3 文件改名冒充 v2，也不伪造 v2 原始数据。原始来源说明。

边界与下一步

本轮没有 CA1 后完整既有 Mesh 矩阵回归；此前的 1,105 项分批 POM 回放不是 CA1 回归。正式色散两批中的失败维持严格原值，按用户要求不继续追微弱色差，也不把辅助控制失败改成通过。两条 NB Pass 已验证的是测试夹具定向 RT 与精确标签，不等于 NBPostprocess Controller/Manager 的整链合成、真正 VFX、Player、其他平台或完整材质 Inspector/Tier。普通 Mesh 仍未全部完成，G3/G4 未放行。 归档说明 · 逐附件 SHA-256。
