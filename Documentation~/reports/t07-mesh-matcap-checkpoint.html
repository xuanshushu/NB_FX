普通 Mesh MatCap 对照：限定切片通过

人话结论：这次把 NBShader 的 MatCap 接到 ShaderGraph 普通 Mesh 表面：在已测的平面、旋转平面和相机角度下，打开 MatCap、关闭 MatCap，以及重复拍摄，Graph 与当前 NBShader 的画面逐像素一致。46 项测试全部通过。这只是 MatCap 的一小片，不表示整个 Mesh 迁移、G3/G4 或 VFX 已完成。

2026-10-01；包输入 64308ec，产品 a26a729。Unity 6000.3.18f1 / URP、Shader Graph、VFX 17.3 / Metal / RenderGraph。unityMCP 不可用，因此在隔离工程独占运行 Unity CLI；没有打开主工程或修改官方包、UniversalTarget、NBPostprocess、三个保护设置。产品源快照固定取自 a26a729，不混入之后的法线贴图工作。

做了什么

Graph 复用 NBShader 已有的 MatCap 坐标和颜色混合函数，采样固定为线性 Clamp；原有 NoMip 标志的第 5 位仍生效。MatCap 不使用普通纹理的 ST、Wrap 或替换采样器。处理顺序保留为提前颜色调整 → MatCap → Emission，没有新增 keyword。

实测范围与结果

  • 46/46 通过，无跳过：23 种参数/姿态 × 正交、透视相机。覆盖混合强度、Alpha、HDR 着色、启停、NoMip、正反面、Mesh 与相机旋转、提前/后期颜色调整和 Emission 顺序。
  • 严格画面对照：当前 NBShader ShaderLab（B）对实际生成的 Graph（C），每项主画面和控制画面在 48×48 内部区域的 RGB 与 Alpha 都为 0 差，重复拍摄也为 0；全部原始帧，包括区域外像素，均为有限数值。渲染目标为 128×128 linear RGBAHalf；保存无损 float32 RGBA 原始帧和 PNG。
  • 不是“两个空白图碰巧相等”：40 项启用功能的对照，关闭/改变 MatCap 至少产生 0.09375 的有效画面变化。另 6 项分别故意更改 ST、Wrap、采样器：这些本来不应影响 MatCap，实测为零影响；同时单独切换 MatCap 仍至少产生 0.257080078125 的画面变化。
