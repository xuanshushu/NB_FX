普通 Mesh 屏幕 Noise 数据接入

人话结论：Graph 现在能把 Noise 贴图算出的“往哪个方向扭、影响多少”送进两条 NB 屏幕扭曲 Pass。用普通 Mesh 实际绘制时，8 项与旧 NBShader 的结果完全一致。另有 2 项只验证 Graph 的备用输入与等价贴图输入一致，不属于旧 Shader 对照。这一步完成的是两条 Pass 读对数据，不是整个 NBPostprocess 后处理系统完成。

2026-10-01；固定产品提交 e2bdae5（父提交 db1e304）。Unity 6000.3.18f1 / URP、SG、VFX 包 17.3 / Metal / RenderGraph。此轮由主 Agent 使用独占隔离 clone CLI，unityMCP 当时无可调用工具。未运行真正 VFX；Graph 的 Support VFX 设置保留，但不能据此宣称 VFX 已验证。按 D24，继续普通 Mesh 完整对照，之前的 VFX 结果仅保留为历史探索。

本片到底做了什么

  • 同一次 Graph 表面计算额外输出两份数据：方向偏移 signedRG，以及影响范围 noiseMask。两条 Pass 读取这份结果，不另算一套 Noise。
  • 遮罩只作用一次。例如 Noise 的透明度是 0.5、遮罩也是 0.5，最终覆盖是 0.25；不会又把方向偏移乘 0.25，造成效果被额外压弱。
  • NBDeferredDistortPass 验证输出的方向和覆盖数据；NBCameraOpaqueDistortPass 验证用这些数据偏移采样真正的 URP 不透明背景纹理。
  • 新增包内 Graph Block 和 SubTarget 接口，保留两个精确 LightMode 标签及原共享 payload 算术；没有修改官方包、官方 UniversalTarget 或原 NBPostprocess。
