9. 必须保留的问题与接线陷阱

  • 两次1105单进程与一次CA58单进程出现整帧空白/非有限/重复差；原因未证实。短CA也能复现，所以不能声称长批次数阈值或Metal driver根因。历史完整保留，后续分批重放仍检查finite/visible/强对照/repeat。见只读宿主审计。
  • CA fixture v2剩余56原XML/log/raw曾被root重用路径覆盖，无法恢复，只有源码+当时26/30摘要；来源错误说明保留。不得伪造或把v3改名成v2。
  • Pass Name是 Universal Forward，而实际LightMode为SRPDefaultUnlit；FindPass读Name，SetShaderPassEnabled读LightMode。不能照同名猜API。
  • CameraOpaque与Deferred精确LightMode仍 NBCameraOpaqueDistortPass / NBDeferredDistortPass；宏需在CF include前，runtime distortion mode不是static Pass identity。CameraOpaque BaseMap强制clamp是原契约。
  • SG CF参数顺序取m_Slots序列，不按数值ID自动排序；新增输入插在输出前，保留旧ObjectId/slot/edge/keyword。
  • 片元Bitangent已含OddNegativeScale；POM fragment不能重复乘。SixWay顶点basis规则另看真实原路径。
  • 屏幕pixel Y适配使用_ScaledScreenParams.y，不能改回_ScreenParams。常规actor layer4，定向screen layer3，旧renderer透明mask排3。
  • 原UV多在preVertexOffset顶点计算，Twirl/Polar/Decal/POM主Pass/两screen才走片元；Cylinder本身不强制片元。Shared mode4在Main计算前读零Main，Main self4先UV0；圆柱global bit同时改变ObjectPos来源。
  • ShaderLab原Flags整数与Graph双16浮点是同一协议两物理宿主，不能把32位数直接Float或发明第二GUI/第二Resolver；默认/Serialized高位/MPB读写需完整验证。
