T08 · VFX 逐粒子 age 连线调查（未通过运行时断言）

2026-09-30 复核纠正：本页记录的是历史失败，不能据此判定产品 Alpha 功能失效。隔离探针把 age→Alpha 对照物放在 GameObject layer 3，而当前 URP-HighFidelity Renderer 的透明层掩码为 55（只包含 0、1、2、4、5，不包含 3）。改到允许的 layer 1 后，相同 VFX 变体的 Metal Player 在 0.15/0.80 两个阶段均可见，运行断言通过。证据与未覆盖范围见纠正复测；原始失败日志仍保留为测试夹具教训。

结论：当前 Unity 6000.3.18f1 / VFX 17.3 / Metal，隔离 VFX 变体将官方 Get Age Over Lifetime [0..1] 的 age/lifetime 双向连至产品 Graph Output 的 _Color.a。导入器保存该连接，生成 shader 确实从逐粒子 buffer 读取 age/lifetime 并构造颜色；但匹配种子的 Player 对照中，常数 alpha=1 的粒子可见，age 连线粒子虽存活却不可见。探针因此以退出码 1 失败；不能宣称已完成逐粒子颜色/Alpha 运行时验收或 G5 放行。测试只改隔离克隆 Assets；产品 VFX 样例未加入这条实验连线。当前无 unityMCP，使用 Unity CLI；未改官方包、NBPostprocess 或主工程 Assets/ProjectSettings，未 push。

两个常数/age 连线隔离变体只差 AgeOverLifetime 节点、图 child 引用与 _Color.a 双向 m_LinkedSlots；产品样例保持原状。强制重导入后这两个链接仍在；age 生成 shader实际有 attributes.age、attributes.lifetime、二者相除并写 output._Color.a，而常数生成 shader保持 alpha=1。这里的 Output 端口不等于 VisualEffect.HasFloat 所查的 Blackboard 公开参数。
