T07 · Graph BaseMap UV 旋转/ST/滚动检查点

结论：当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal / RenderGraph，产品 Graph 在普通 Mesh 上经原共享 NBFX_BuildBaseUVsV1 的 UV0 子集支持 BaseMap 旋转、ST、XY 时间滚动及旋转速度；各非零参数均引起受控画面变化。默认值下先前 Flags、Mask、Dissolve 和双扭曲 Pass 数值回归保持；真正 VFX Mesh 默认值的 Metal Player 仍可见。G4/G5 未放行。无可用 unityMCP，使用隔离克隆的无可见窗口 Unity CLI；未改官方包、UniversalTarget、NBPostprocess 或主工程 Assets/ProjectSettings，未 push。

包内 UV host向共享 NBFX_BuildBaseUVsV1提供零 flags/UVMode/CustomData 的 UV0 子集、_Time.y和原参数 _BaseMapUVRotation、_BaseMapUVRotationSpeed、_BaseMapMaskMapOffset.xy。顺序保持“旋转 → _BaseMap_ST → 时间滚动”。BaseMap Sample 关闭 SG 自动 ST，改由 Graph 显式 _BaseMap_ST=(1,1,0,0) 属性传给共享函数；生成 shader 的 Texture2D struct 中自动变换确为 identity，未双重应用 ST。Mask/Dissolve UV 未在本切片修改。
