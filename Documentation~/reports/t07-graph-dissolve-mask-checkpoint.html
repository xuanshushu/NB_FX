T07 · Graph 可选 Dissolve Mask 双模式检查点

结论：当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal，产品 Graph 增加了可选 Dissolve Mask 单贴图，沿用原共享 NBFX_PrepareDissolveV3/NBFX_ResolveDissolveV3 两阶段数值合约。受控 Mesh 测试中启用、前期/后期模式、R/A 通道、独立 ST 及旋转均改变最终画面；默认关闭时既有六张 PNG 逐字节保持，真正 VFX Mesh 默认值 Player 冒烟通过。不是完整溶解功能，也不构成 G4/G5 放行。

Graph 新增原 ShaderLab 同名 _DissolveMaskMap（默认白）、_DissolveMask_Toggle（默认 0）、_DissolveMaskMode（0=Prepare 前过程模式，1=Resolve 后遮罩模式）。Mask 在主 Dissolve 与自身 Toggle 都开启时才采样；通道读取原 packed ColorChannel bits12–13，强度取 _Dissolve.z；UV0 使用各自纹理 ST、共享 Dissolve 旋转，不额外滚动。未新增 keyword、Pass，未复制共享算术。
