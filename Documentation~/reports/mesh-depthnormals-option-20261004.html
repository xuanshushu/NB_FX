近距 receiver 给出的因果证据

Native NBShader 源码和实际 Pass 列表没有 DepthNormalsOnly。旧 Graph 默认多出的 Pass 在原远距场景中改变 AO 缓冲，但没有可见最终图差异；本片让 NB actor 始终启用，并把 Lit receiver 放在按实际 VAT 输入计算的最低几何位置下方约 0.02 单位。SSAO radius=0.25、direct-light strength=0.25，独立 Lit cube 全程保持相同布局。

产品修改只有一个生成选项

包自有 NBGraphUnlitSubTarget 增加序列化 m_NBMeshDepthNormals=true。普通 Mesh 显式 false 时，只在本包 delegated Pass 组装时过滤 LightMode 为 DepthNormalsOnly 的描述符；其它 Pass 与现有 BackFirst 实现保留。中央标准 Graph 在唯一活动 NB target 对象中明确设置 false，恢复 Native 默认 SSAO 参与范围。

DN 选项本身不新增材质 Float、keyword、HLSL 或 packed flag，不修改官方包、UniversalTarget 或 NBPost。Graph 使用当前 Root 与已审 Tier Float 增量动态合成，再追加 DN 目标字段，未用旧 whole Graph 覆盖 Tier。

版本化布局合同与新十项结果

旧 core 的 98 条断言语句、private 三参数 ABI 和原八项身份保留。新增布局期待默认 true；新 V2 身份明确期待编译后 FindPass=-1。只有 presence/enabled 布局期待按版本区分，finite、visible、repeat、AB/BC、VAT/帧强响应与原误差阈值没有放宽。旧 on-layout 身份应使用含 DN0 的 Graph，不能把它们直接放到 off 配置下再混记结果。
