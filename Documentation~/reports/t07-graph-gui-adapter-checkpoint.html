T07 · Graph GUI 薄适配检查点

结论：当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 的隔离工程中，Mesh Graph 已注册包内 NBShaderGraphGUI，原 ShaderLab 保持 NBShaderGUI，真正 VFX Mesh 仍注册官方 VFXShaderGraphUnlitGUI。Graph 材质的 URP 透明状态校验实测有效；G4/G5 未放行。当前无可用 unityMCP，使用无可见窗口的 Unity CLI；未改官方包、UniversalTarget、NBPostprocess 或主工程 Assets/ProjectSettings，未 push。

实现只在包内：SubTarget 区分 Mesh/VFX 的 Custom Editor；asmref 桥编入当前 URP Editor 程序集以继承其 internal ShaderGraphUnlitGUI，保留官方 Surface Options/Advanced/ValidateMaterial，不复制 URP 代码或反射运行时实现；NBShaderGraphGUI继承原 NBShaderGUI，Graph 专用 Root 只绘制存在的 Graph 属性，不让 Graph 材质进入依赖完整 ShaderLab 属性和 Flags 的 NBShaderSyncService。这不是已完成原 NBShader 功能面板的等价复用。
