普通 Mesh 表面功能统一 B/C 对照

人话结论：把同一块普通 Mesh、同一张纹理、同一套参数，先交给原 NBShader（B）再交给 Shader Graph（C）渲染。本轮已接入的 44 个预设，各在正交和透视相机下测一次，88 项的完整 RGBA 逐像素相同，重复渲染也没有变化。另有 4 项实际生成并渲染的 Master Preview，与运行时 Graph 相同。这不是“所有功能已经完成”，也不放行 G3/G4。

2026-09-30；主工程输入 9d0f998，包输入 bbe0a72（产品代码仍为 6f51533）。这些证据对应后续通用采样修复前的产品，不提前宣称 Wrap/ForceNoMip 已通过。测试源码和完整输入 hash 已归档。Unity 6000.3.18f1 / URP、SG、VFX 包 17.3 / Metal / RenderGraph。当前没有可调用的 unityMCP，因此只在隔离克隆使用 CLI；没有打开主工程或要求用户值守，没有运行真正 VFX。

本轮覆盖了什么

预设组普通 Mesh 同输入 B/C
基础色与 AlphaBase、主纹理 Alpha 的 R/G/B/A、AlphaAll、ColorA、Timeline、bit29 RGB×Alpha、bit28 背面颜色、非白顶点色与 bit9 忽略。
双层叠加与颜色渐变Overlay1/2 加/乘及 Alpha 模式；Color Ramp 的 UV/贴图来源；Hue/Contrast/Saturation/Refine，前期和晚期的 ColorA 排序。
遮罩和溶解单层/三层 Mask、Refine、三层 packed Alpha Gradient；Dissolve 单图、process/late Mask、边缘线；Dissolve Ramp 贴图/packed Gradient 及加/乘。
Fresnel 与深度Fresnel Alpha/颜色/Alpha 关联/Invert，距离淡出、Soft Particles、Depth Outline；一组深度组合和一组表面组合。深度相关预设由相机明确提供深度纹理。
生成 Master PreviewBase 与表面组合 × 两种相机，共 4 项。用当前官方 PreviewManager 相同的 Generator / GenerationMode.Preview 入口生成 Shader，再实际渲染；不是仅查看源码，也不是可见 Graph 窗口交互测试。此处没有测试 Preview 的场景深度功能。

如何避免“双方都没生效”的假通过

除 Base 默认预设外，逐项保留“关闭功能”的 Graph 对照图；84 个普通 Mesh 功能预设和 4 个 Preview 功能预设，与关闭对照的 RGBA 最大差都大于 0.01。组合预设仅证明组合有作用，不能证明组合里每一个功能都独立改变结果；单功能预设另行覆盖。纹理使用线性 RGBA(64,128,160,192)，白色/原色 tint 避免把 SG 颜色 UI 编码混入本轮算术判定，不代表任意颜色输入或实际 Inspector 已验收。

第一次扩展矩阵为 90 通过、2 失败：顶点色预设的“关闭”材质也使用了非白顶点色，所以开关画面相同，正对照断言正确地报失败；当时 B/C 的 RGBA 差仍为 0。只修正关闭对照材质的 Flags1 bit9，未改产品 Shader，复跑 92/92 通过。失败 XML · 原始日志。
