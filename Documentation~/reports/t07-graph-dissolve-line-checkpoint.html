T07/T08 · 溶解描边色的 Graph Mesh 与真正 VFX Mesh 限定检查点

范围与结论：包仓库产品提交 30bbe66 在原有 Dissolve V3 阶段保留软阈值处理前的数值，按原 ShaderLab 的 Flags1 bit5 对 RGB 做描边混合；Alpha 仍只由原 coverage 控制。Graph 增加原同名 _Dissolve_Vec2、_DissolveLineColor，Mesh Inspector 在已有 Dissolve 分组内绘制属性与 packed bit 切换。没有新 keyword/Pass，也未改官方包、UniversalTarget、NBPostprocess 或主工程 Assets/ProjectSettings。当前 Unity 6000.3.18f1、URP/SG/VFX 17.3、Metal 下，受控 Mesh Graph/ShaderLab B/C 和真实单粒子 VFX Output 均通过；不是完整 Dissolve、GUI、G4/G5 放行。
