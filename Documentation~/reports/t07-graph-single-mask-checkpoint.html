BaseColor Custom Function 在原共享 NBFX_ComposeBaseColorV1 后，按原 Flags1 bit7、packed 通道位 2–3、_MaskMapVec.x 和 _MaskRefineVec.xyz 调用唯一的 NBFX_ResolveMaskCoverageV3，把结果乘入 Alpha；两条自定义扭曲 Pass 读取同一个 SurfaceDescription.Alpha。Graph 新增 _MaskMap、_Mask_Toggle（默认 0）、参数向量与颜色通道低 16 位属性，没有新增关键字。生成 Mesh Shader 中 _MaskMap_ST 进入 UnityBuildTexture2DStructInternal，采样经 GetTransformedUV(IN.uv0.xy)；VFX 生成 Shader 中参数进入 GraphProperties 并由 GetElementPixelProperties 填充。
