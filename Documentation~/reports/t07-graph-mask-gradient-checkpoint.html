T07 · Graph 三层 Mask Gradient 检查点

限定结论：当前 Unity 6000.3.18f1 / URP、SG、VFX 17.3 / Metal 的隔离工程中，产品 Graph 的 Mask1/2/3 可由原 Flags1 bit2/3/4 分别选择 packed alpha gradient；复用已对 Frozen ShaderLab 做逐像素 A/B=0 的 NBShaderPackedGradientV1.hlsl，渐变分支不采遮罩纹理。Mesh 对照中三层切换与原有不对称 wrap 模式均产生预期方向的非零画面差；真正 VFX Mesh 默认关闭路径的 Player 存活可见、两个精确扭曲 Pass 保留。它不是完整 Mask、数值级 B/C 或 G4/G5 放行。

实现只改Graph 颜色函数和产品 Graph；新增 14 个已连通输入：WrapFlags 低/高 16 位及三层各 4 个原名 Gradient Count/Float 参数。不增加 keyword 或 Pass。Mask1/3 用变换后 UV.x，wrap mode 0/2 为 frac、1/3 为 saturate；Mask2 用 UV.y，mode 0/3 为 frac、1/2 为 saturate。每层仍需其 Toggle 开启；三层值相乘后才进入共享 Mask V3 的 Refine/Strength。原 ShaderLab 渐变 evaluator 的提取由独立验证记录注明。
