NB_FX 重构计划

共享功能 HLSL，保留 NBShader，新增只面向 VFX Graph 的 NBShader_VFXGraph。实施已获授权；G0 基线与当前 URP/Metal 的 GF Pass 可行性均已通过，G1 设计接口已限定范围放行，G2–G7 尚未放行。

更新：2026-09-30 · D24：当前集中完成普通 Mesh / Graph 完整对照；G3/G4 未放行；真正 VFX 留到之后，HDRP 待最后轮次选择 · 不修改官方包

已确认的产品范围

普通 Mesh 与现有宿主继续使用 NBShader（ShaderLab）；NBShader_VFXGraph 最终只服务 VFX Graph。让 Mesh 使用 Shader Graph 材质，仅用于隔离验证，不是新的用户工作流。

项目确认内容
重构对象以 NBShaders2 为主；旧 ParticleBase 不改。当前检出没有旧 NBShaders 实现，不以过期目录说明代替源码。
原路径保留行为、材质协议、GUI、辅助组件、Feature Tier、Pass 与 NBPostprocess；UI、Sprite、UIParticle、Universal2D 仍归原路径。
新路径产品名 NBShader_VFXGraph；不要求支持 UI、Sprite、UIParticle、Universal2D。宿主收缩不授权删减范围内的效果功能。
GUIShaderLab 与 Graph 尽量共用同一 NB GUI 实现；VFX Output 的接入或薄适配须单独验证，不维护两套独立 NB GUI。
VFX 创作直接在 Graph / Output 配置；连线与逐粒子数据由 VFX 管理。不建设材质导入、同步或转换工作流。
Graph 材质Mesh 验证阶段不要求与原材质序列化兼容；兼容仅为加分项。原 ShaderLab 材质兼容仍是硬要求。
版本当前先在 Unity 6000.3.18f1 / URP、SG、VFX 17.3 跑通；旧版本兼容最后评估，不阻挡当前 Gate。最终最低版本以实测为准。
平台新 VFX 路径以较新 DirectX、Metal、Vulkan 为候选，具体最低版本待验证；不支持 OpenGL ES，XR 不在正式范围。原 ShaderLab 旧版/旧 API 范围后续按实测评估，当前环境行为须保留。
禁止事项不修改官方包；不擅自改用标准 Lit / Six-Way Target；不能自行接受能力降级。
当前授权用户于 2026-09-25 授权从 T00/G0 实施，G0 后进行 T00A/GF；不授权修改官方包、擅改 Target/NBPostprocess 或删减功能，未经再次要求不 push。
阶段顺序URP 常规 Mesh 产品继续由现有 NBShader 支持；验证时先完成普通 Mesh 上的 URP ShaderGraph 全功能对照与 G3/G4 审核，再开展真正 VFX 的 G5/G6。已有 VFX 结果仅为提前探索。HDRP 作为最后轮次待选目标；进入 HDRP 前先设计按管线选择依赖内容的安装流程。见D24及 D20 / Q08。

三条验证主线

01 · ShaderLab 回归
冻结原始 ShaderLab ↔ 重构 ShaderLab。验证共享 HLSL 拆分不改变原行为。

02 · Mesh / Graph 验证
重构 ShaderLab ↔ Mesh 上的 Shader Graph。验证功能组合、Pass、GUI 与 NBPostprocess。

03 · VFX 验证
已验证的 Graph ↔ 真正 VFX 输出。验证 Output、参数、逐粒子数据与渲染兼容。

用户所说的“两步走”是主线 02 与 03：先完成并审核 02，再开展 03，不逐功能交错验证。03 不能代替 02；02 通过也不能宣称 VFX 已通过。Graph 保留 Support VFX Graph 设置不改变这一顺序。
