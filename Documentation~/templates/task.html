任务书模板

为后续 SubAgent 提供独立、可执行且可审核的任务定义。

更新：2026-09-25 · 模板 · 未派发 · 不修改官方包

这是模板，不是已派发任务。复制后填写所有“待填写”，绑定最新基线和决策。不要复制出第二套独立规范。

任务信息

字段填写内容
任务 ID / 名称待填写
目标 Gate / 前置 Gate待填写
执行 Agent / 主 Agent待填写
状态 / 日期未派发；待填写
接口版本 / 基线 / commit / diff hash待填写；主工程与 NB_FX 分别记录
精确文件所有权 / Editor 窗口待填写

目标与非目标

待填写：需要实现的可观察结果、应保留的原行为、明确不做的内容、禁止的替代路线。不得以“尽量”为未审批删功能留下默认授权。

输入、依赖与修改范围

待填写：阅读材料、前置产物及 hash、允许修改的精确绝对路径、只读路径、接口消费者和冲突处理。Assets 例外与原因逐项列明。

实施方法

  1. 待填写：源码调查与根因/目标定位。
  2. 待填写：每个可回退切片、接口接入和迁移顺序。
  3. 待填写：由主 Agent 串行安排的 Unity 变更与验证。

验收与交付

待填写：case ID、输入、预期、阈值、运行环境、截图/数值/Pass/Console/Player/性能证据、报告与回退点。不能只以编译或 SubAgent 自述作为验收。

阻塞与变更

待填写：哪些情况立即停下、向谁汇报、哪些变更必须请用户决策、如何保护用户改动。接口漂移须先协调；官方包不得修改。
