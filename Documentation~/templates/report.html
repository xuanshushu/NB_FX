  1. 待填写：恢复基线和目标实现、加载受控场景。
  2. 待填写：先读取 Editor/编译/Console 状态，核对环境。
  3. 待填写：执行命令或 UI 操作及固定输入。
  4. 待填写：输出位置、数据读取与比较命令。

原始证据与媒体

  • 保留 Console 原始日志、命令输出、测试 XML/JSON、生成 Shader / Pass 清单与 build 记录。
  • 图像包含 Reference / Candidate / Diff；必要时保留 HDR/Depth/Alpha 数据，不能仅留缩略图。
  • 填写 NBPostprocess 实际 Pass 执行、RenderTarget 格式、Blend 与合成结果。
  • 附采样数、variants、SRP Batcher、CPU/GPU/显存等受影响指标；不适用项写明理由。
  • 截图和视频使用相对路径与说明，不嵌 Base64；附件大型媒体使用 LFS。

差异、失败与已有问题

待填写：回归、基线已有问题、环境问题、平台限制、用户批准差异分别列出。0 个新 Console Error 不等于 Shader 功能通过。1 条既有警告也不能在没有归因的情况下自动豁免。

主 Agent 审核与 Gate 结论

待填写：审核过哪些产物、复跑哪些 case、证据是否对应当前实现；通过/不通过/待环境、批准例外的决策链接、未解决项和下一阶段权限。SubAgent 不自行放行。
