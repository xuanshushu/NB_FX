已确认决策

编号决定替代/排除
D01NBShader 保留普通 Mesh 与现有宿主；NBShader_VFXGraph 最终服务 VFX。不推出普通 Mesh 的 Graph 用户工作流；不要求新 Graph 支持 UI/Sprite/UIParticle/Universal2D。
D02三条验证主线独立，尤其 Mesh / Graph 与 VFX 两步走。不能直接跳到 VFX，或把最小可用与功能等价合并。
D03不修改官方包；先验证所需自定义 Pass / LightMode。不默认反射注入、修改 PackageCache、伪装程序集或手改生成 Shader 解决。
D04ShaderLab / Graph 尽量共用 NB GUI；VFX GUI 独立验证。不维护两套独立 NB GUI；不预先承诺可直接嵌入 VFX Output。
D05VFX 直接配置 Graph / Output，连线与逐粒子数据由 VFX 管理。取消材质导入、同步、转换工作流。
D06Graph 测试材质与原材质的序列化兼容不是硬要求。可选转换仅用于验证，不成为产品或架构限制；原 ShaderLab 兼容仍必须保留。
D07改用标准 Lit / Six-Way Target 等其他实现必须先讨论并获得同意。不能仅凭等价测试自行替换。
D08新路径最低版本可在 Unity 6000+ 中确定，先 6.3，后续至 6.5。不再要求新路径回到 2021.3；不自动批准原 ShaderLab 放弃旧兼容。
D09新 VFX 路径保留较新 DirectX、Metal、Vulkan 候选；接受不支持 OpenGL ES。XR 不在正式范围。具体最低 API、OS、设备与版本仍待验证；原 ShaderLab 兼容要求不因 VFX 排除 GLES 而缩减。
D10复制 NBShaderSample 与必要资产，保留原始/重构/Graph 三组，后续增加 VFX。不能只复制材质当作原实现冻结，也不能删掉前期对照。
D11正式文档采用 Documentation~ 内可独立打开的简单 HTML；index.html 仅列文件入口，不使用公共 CSS、JS、页面外壳或生成流程。不维护重复 Markdown 正文；证据媒体使用相对链接与 LFS；测试资产在 Unity 可导入范围。
D12CLI 1.0.0-beta.11 / Pipeline 0.7.0-exp.1 已单独授权安装，版本固定。不自动升级；工具连通不等于回归通过；不视为 Coplay MCP 已安装。
D13本轮仅计划与文档，禁止开始重构和 SubAgent 执行。后续任务书是执行说明，不是当前启动指令。
D14文档正文中文，专业术语保留原文，不附中文释义。不制作术语翻译表。
D15允许把 Pass 可行性试验提前到 G0 后、大规模 HLSL 重构前，单列 T00A/GF。不等于本轮启动试验；GF 不替代 G2/G3/G5，也不授权修改官方包或自行选择降级方案。

待证据后讨论

编号问题触发/责任
Q01Graph 所需自定义 Pass / LightMode 是否可用；不可行时接受哪种局部替代？先 T00A / GF，再 T06 / G3 正式复验；原始目标失败后给出最小复现、官方限制与候选代价，不提前建设替代架构。
Q02VFX Output 是否能复用 GUI；不能直接嵌入时薄适配到什么程度可接受？T08 / G5；附配置、连线驱动、RenderState 的实际数据流与界面证据。
Q03Override Z、背面先绘制、Stencil、透明阴影等能力如何保持？T06/T07 与 T08/T09；逐项列限制，不能统一降级。
Q04最低 Unity 6000.x、DirectX/Metal/Vulkan 具体版本和 OS/GPU 设备矩阵。T10，结合前序最小方案特性；OpenGL ES 已排除新 VFX 范围，不再作为悬而未决项。
Q05正式 Output 类型清单、必须覆盖的 VFX Mesh/VAT 数据组合。T08 先最小验证，T09 前确认；不凭便利缩小范围。
Q06图像容差与新增路径性能预算。基线校准后、全量验收前确认，不在失败后放宽。
Q07若共享重构影响原 ShaderLab 的旧版本兼容，如何处理？主 Agent；当前没有放弃原兼容要求的批准。

决策流程

  1. 发现问题，停止受影响分支，保存最小复现和原始证据；其他无关已授权任务可继续。
  2. 提交原目标、限制、候选实现、影响功能、版本、性能、维护成本、回退方案与推荐意见。
  3. 等待用户明确选择。沉默、工具失败或 SubAgent 自认为可接受，都不构成批准。
  4. 用决策模板记录答复，更新接口、任务书、用例和受影响 Gate。

技术试验成功只能证明候选可行，不能代替用户对不同实现路线的批准。
