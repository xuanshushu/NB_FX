Gate 清单

Gate目标必备证据不通过时
G0基线可复现、验证工具可信。原 shader/HLSL 依赖闭包和配置哈希；基线重放；样例复制方案；截图、日志、测试与 Reload 能力核验。先修复基线/工具，不开始重构。
G1接口与拆分规则冻结。逐属性/Flags/阶段/Pass 映射；函数签名；文件所有权；模块测试方案。冲突交主 Agent 协调，不各自发明接口。
G2ShaderLab 重构回归通过。原始与重构图像/数值/材质/GUI/Pass/NBPostprocess 对照；旧路径未支持项和已有问题明示。定位最小回归切片，回退或修复，不用 Graph 结果替代。
G3Mesh / Shader Graph 最小方案跑通。Custom Function、基础参数、所需自定义 Pass / LightMode 与 NBPostprocess 双路径证据；无官方包修改。若 Pass 不可行，交具体限制与最小替代候选，待用户批准。普通颜色可见不算通过。
G4Mesh / Shader Graph 在确认范围内尽量等价。功能与组合覆盖、共享 GUI、深度/阴影/高级状态、生成代码、Player、性能对照；所有差异有结论。未解决差异不得静默接受；需要用户确认例外或继续修复。
G5真正 VFX 最小方案可用。真实 VFX Output、受控粒子数据、空间、GUI 入口/薄适配可行性、与已验证 Graph 的对照和 NBPostprocess。记录 Output/GUI/数据限制；不回避到普通 Mesh 宣称成功。
G6VFX 确认范围完整回归。确认 Output 类型、功能、VAT/光照、动态输入、同屏新旧路径、管线与性能证据。缺口逐项讨论，不减少范围后自行通过。
G7版本/API/发布验收。明确最低版本、6.3 与 6.5 及范围内版本族、各 API 的真实 Player 证据；文档、回退和依赖检查。未测项目标记未验证，不标为支持。

放行规则

  • 主 Agent 审查代码、资产、日志、截图与可复现步骤，核对 commit / 工作区 diff hash / 输入 hash / 版本 / API。SubAgent 自述完成不能放行。
  • 每个必测项只允许通过、失败、未运行、待环境、用户批准例外等明确状态；未运行不是通过。
  • “尽量等价”不表示自动容忍可见差异。每个差异必须归为回归、基线已有问题、平台限制、用户已批准差异之一。
  • 范围和验收容差不能由实现者在看到失败结果后自行放宽。调整先记录用户决策，再更新用例和 Gate 版本。
  • Gate 记录必须含审核人、时间、任务 ID、证据链接、未解决事项、批准的例外、回退点与后续可启动任务。
  • 接口、核心功能或 pipeline 变更导致上游证据失效时，标记受影响 Gate 需复验，不沿用过期通过状态。

必须向用户升级的情况

  • 所需自定义 Pass / LightMode 无公开且可维护的方案；需要改官方包或内部生成流程。
  • 拟改变 NBPostprocess 调度、扭曲编码、Graph 渲染方式或使用替代多次绘制路线。
  • 拟改用标准 Lit / Six-Way Target、替换现有公式、调整效果范围或降低精度。
  • VFX Output 无法复用 GUI，薄适配仍不足；或必须维护独立 NB GUI。
  • 拟牺牲原 ShaderLab 材质兼容或旧版本支持；拟改变公共属性/Flags/关键字。
  • 平台无法达到功能或性能要求；拟删减 API、Output 类型或版本。
