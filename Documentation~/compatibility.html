DirectX、Metal、Vulkan 的“较新版本”仍是范围意向，不是技术可用性证明。T10 必须先检查该 Unity/VFX 版本的官方平台能力和本地生成代码，再确定设备和用例；缺硬件标记待环境，不能用模拟或 Editor 编译冒充实机通过。Unity VFX Graph 17.3 对 URP 还要求非 Gamma color space，并要求 compute shaders 与 SSBO；后续版本需重新核对对应官方资料。官方依据。

兼容策略

  • 共享 HLSL 保持一份；版本差异集中在小型宿主/URP/Graph 适配，不复制整套算法。
  • Graph 资产格式按实际最低版本选择；若需少量版本族包装，先记录维护成本，不将高版本保存的 Graph 自动当作低版本可读。
  • 原 ShaderLab 稳定 API、Flags 与材质协议保持；新路径依赖用适当程序集/条件隔离，不能令未使用 VFX 的原用户被迫安装高版本依赖。G1 必须列出 package.json、asmdef/versionDefines、Graph/VFX 资产放置与依赖策略；G2 做 Unity 2021.3 原路径 smoke，不把风险留到 T10。
  • 不同 Unity 版本使用隔离项目/checkout 与 Library；不能反复降级打开当前用户工程。
  • CLI / Pipeline 是验证工具依赖，不默认打包成 NB_FX 产品依赖；若产品代码出现对此依赖，须说明理由并审核。
  • 保留已存在的 RenderGraph 与适用 Compatibility 路径；新版本缺失某路径时准确标记，不伪造等价测试。
