实施方法

  1. 按确认 Output 类型建立粒子数、空间、变换、custom attributes、纹理/Flipbook、生命周期、GPU events（若纳入范围）与 Bounds/sorting 测试矩阵。未确认类型不能自动纳入或排除。
  2. 运行全部确认效果与高风险组合，特别覆盖 VAT 高 UV/Buffer、光照输入、Fresnel、Dissolve/Mask、深度衰减、Alpha、OverrideZ 和背面顺序的适用性。
  3. 分别验证 opaque/deferred distortion、ScreenColorCopy、RenderGraph/Compatibility、主相机配置及已确认相机组合；同屏混合 ShaderLab 和 VFX 防止全局资源互相污染。
  4. 核对 per-particle 与 uniform 默认值、连线覆盖、Disable/Enable、Reinit、暂停、固定步进、Domain Reload 和构建后表现。不得把无法完全锁定的 GPU 时序误差直接定为实现错误或通过。
  5. 执行 Player、variants/stripping、CPU/GPU/显存与粒子规模测试；性能阈值在比较前由主 Agent 固定。功能修复若修改共享核，重新跑 A/B 和 B/C 受影响用例。

验收标准

  • 确认 Output × 功能 × NBPostprocess 清单有完整结果；全部缺口有明确状态和用户结论。
  • 同屏新旧路径、动态运行、GUI/连线和 Player 均无未批准回归。
  • 受影响上游 Gate 复验有效，不能只证明 VFX 修复而破坏 ShaderLab。

检查结果必须关联源码/资产 hash、环境与 case ID。未运行、待环境、失败均不能写成通过。主 Agent 按Gate 规则审核后才可放行。
