实施方法

  1. 以 Input 与 Forward 的实际调用关系列出 UV 来源、ST、极坐标/旋转/偏移、Flipbook、运动、CustomData、wrap 和 channel 行为，追踪到属性。
  2. 先迁移纯数学与协议解码，再迁移 UV 计算和采样 wrapper；不在公共模块中硬编码 AttributesParticle 或 Graph 自动生成变量名。
  3. 保留 Vertex / Fragment 分工及插值方式，明确 texture / sampler 由宿主提供。ForceNoMip、SampleLevel、隐式导数和显式梯度不能互换。
  4. 建立细分 UV、非均匀缩放、负 UV、边界 wrap、动画帧过渡、CustomData 缺省和高位 Flags 的数值/纹理夹具。
  5. 每完成一个垂直切片提交文件 diff 与调用示例，由 T05 在单一 Editor 接入 A/B 对比。只读协调 T03/T04 的采样需求。

验收标准

  • 全部 UV 模式、Wrap、Channel 与 CustomData 解码可追踪并通过对应测试。
  • 无新增未批准关键字；采样次数、LOD 与精度无无意变化。
  • 与 Surface / Geometry 消费端接口一致，ShaderLab 集成证据由 T05 回传并复核。

检查结果必须关联源码/资产 hash、环境与 case ID。未运行、待环境、失败均不能写成通过。主 Agent 按Gate 规则审核后才可放行。
