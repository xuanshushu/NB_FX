实施方法

  1. 以具体依赖特性确定最低版本，不把“6000+”当作每个版本已经支持。为纳入范围的版本族和补丁组合建立独立工程/Library，固定 URP/SG/VFX 与 Renderer 设置。
  2. 首先复验 6000.3，再在可获取且获准使用的版本中扩展到 6.5。工具或 Editor/包升级另行授权；本任务不自动升级用户主工程。
  3. 按实际设备建立 DirectX、Metal、Vulkan、OpenGL ES 的 Player 测试。GLES 的 VFX 能力特别先查版本限制并实测；不支持时登记阻塞/待决策，而非沿用 ShaderLab 支持推断。XR 不纳入。
  4. 分别验收原 ShaderLab 旧版本要求和新 VFX 范围，版本适配隔离在 host 层，公共算法不堆砌各引擎/版本条件。原路径 2021.3 规则若要改变必须另议。
  5. 验证 FeatureLevel、SVC、stripping、材质/Graph 导入、无开发辅助工具时的产品运行；Pipeline/CLI 只作为验证工具，不无意增加发布包运行依赖。
  6. 收集每格环境、build、Console、截图、Pass、性能证据，清理仅测试注入，保留验证资产与文档；整体验收前再跑三条主线关键 smoke。
  7. 更新实际接口、决策、支持矩阵、限制和回退指南。发布说明不得包含未跑平台承诺；原 ParticleBase 不变。

验收标准

  • 每个标为支持的版本/API 单元都有真实环境与 Player 证据，不以编辑器单平台截图替代。
  • 全部必需矩阵缺口有用户批准处理；原路径兼容和无官方包修改要求保持。
  • 可从确定回退点恢复旧路径，文档与实现一致，维护任务/风险均有责任人。
