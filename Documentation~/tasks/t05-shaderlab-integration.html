实施方法

  1. 对每批依赖模块先审查签名、顺序、CBUFFER、资源声明和 keywords，按基础→UV→Surface→Geometry/Lighting→Pass 的顺序合并。
  2. 保持 Shader 名称、GUID、Properties、默认值、packed Flags、Pass 名称/顺序/LightMode、CustomEditor、RenderQueue 与现有材质脚本入口。中央入口只负责输入装配、模块调度和输出。
  3. CBUFFER 与实例化声明保持一致，检查 SRP Batcher。禁止将现有材质属性从一个 Pass 移至另一个不兼容布局，也不添加无必要的 multi_compile。
  4. 逐批运行 A/B 对照、Console 与编译检查，覆盖七个 Pass、背面先绘制、OverrideZ / SV_Depth、Stencil/Portal、ColorMask、UI/Sprite/UIParticle/Universal2D 等原宿主。
  5. 按 NBPostprocess 原契约分别验证 opaque distortion、deferred RG distortion、ScreenColorCopy 和合成；RenderGraph / Compatibility 两条路径分开记录。
  6. 验证 GUI 状态、关键词、材质序列化、运行时 Material/MPB 修改、FeatureLevel、SVC、Player 和性能。出现已有 bug 时登记，不与本次重构混改。
  7. G2 前在隔离的 Unity 2021.3 环境运行原 ShaderLab 路径 smoke，检查包导入、Shader 编译、材质与基础 NBPostprocess；不在用户主工程上降级。若新 Graph/VFX 资产或代码使旧版本无法打开，先修隔离策略，不能推迟至 T10。

验收标准

  • A/B 确认范围内功能和行为无未经批准变化；原材质不需迁移。
  • 每个 Pass 和 NBPostprocess 双路径具有执行证据；仅生成 shader 编译成功不足以通过。
  • 中央逻辑确实复用新模块，无保留两份可逐渐分叉的效果实现；原有脚本与 GUI 仍可用。
  • 原路径 2021.3 smoke 有独立证据；完整旧版本矩阵仍由 T10 负责。

检查结果必须关联源码/资产 hash、环境与 case ID。未运行、待环境、失败均不能写成通过。主 Agent 按Gate 规则审核后才可放行。
